# Chinese UTF-8 Encoding ROS (`scripts/chinese-encoding`)

>

## npm (run at **rhProject root**)

```bash
npm run verify:chinese          # gate: v3 src + Cursor metadata + shared docs
npm run scan:chinese            # full monorepo scan (mobile, Java, etc.)
npm run fix:encoding            # repair v3 meta, docs, rules, repo doc, this README
npm run repair:chinese-from-v2  # destructive: Vue2 template overwrite
```

In `wk-train-center-ui-v3`: `npm run verify:chinese` (prebuild uses the same).

## If you see garbled Chinese here

1. `node scripts/chinese-encoding/_write-readme-utf8.mjs`
2. In the editor: status bar encoding -> **UTF-8** -> Reopen
3. Do **not** use PowerShell `Get-Content` / `Set-Content` on Chinese source files
