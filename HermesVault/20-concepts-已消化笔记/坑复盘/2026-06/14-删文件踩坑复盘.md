# 删文件踩坑复盘（2026-06-14）

## 事故

`rm -f <多个文件>` 把 `船海行业公网内容合法使用方案调研报告.md`（git 无版本）连带删了，**永久丢失**。

## 根因

- 想当然删文件，没先 `ls -la` 看目录实际内容
- 该文件没进 git（git ls-files 找不到），无版本可恢复
- `rm -f` 多文件太狠，**没有二次确认**

## 铁律（强制）

1. **`rm` 一次只列一个文件**（多文件场景也拆成多次 `rm`）
2. **删前必须 `ls -la` 看目录实际内容**
3. **删前必须 `git ls-files <path>` 确认 git 追踪**（git 没追踪的就不能 `rm -rf`，要 `mv` 到收纳盒）
4. **git 无追踪的文件要保留**：要么 commit、要么 mv 到 `_private_assistant_archive`
