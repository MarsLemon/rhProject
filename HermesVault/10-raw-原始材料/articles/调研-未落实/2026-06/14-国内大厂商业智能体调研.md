# 国内大厂 To B 商业智能体调研（船舶行业适用版）

**调研日期**：2026-06-14
**筛选原则**：从全部 To B 商业智能体产品中筛出**可在船舶/船海行业落地**的（产品已成熟、行业无强合规壁垒、能对接船舶业务场景）。
**筛除标准**：① 强行业专属（金融/医疗/政务客户验证集中）；② 强合规壁垒（医疗/政务需资质）；③ To C 个人订阅；④ 编程助手。
**不含**：AI 编程助手（Cursor/Copilot 等）、To C 对话 App（ChatGPT/Claude/Kimi 等个人订阅）。

## 六、补充事实

- **百炼 2026.05 接入模型**：GLM-5.1（智谱）、Kimi K2.6（月之暗面）、Minimax M2.7、阶跃星辰、爱诗科技、生数科技等 10+ 家。
- **Coze Studio 开源协议**：Apache 2.0，可商用，依赖 MySQL（不接 PG）。
- **私有化报价区间**：智能体平台 + 知识库类私有化通常 10-50 万（一次性 + 年维护）；工业 CRM/客服私有化 10-30 万。
- **公有云按 token 报价**：基础模型 0.0008-0.04 元/千 token；旗舰模型（如 Qwen3.7-Max）0.04-0.12 元/千 token。
- **常见座席费**：智能客服/CRM 类按席年付 1000-5000 元/席/年。
- **船舶行业相关落地**：售后宝（已落地工业设备售后）、卡奥斯天智（制造业）、帆软 FineBI（船舶/重工企业有案例）。

## 七、调研局限

- 调研范围以国内大厂为主，海外产品（Salesforce/Tableau/Power BI 等）仅列示。
- 部分厂商报价不公开，仅给量级，实际价格需走商务流程。
- 行业垂直 Agent 的"船舶行业深度"参差不齐，需逐家试用验证。
- "船舶维修工务助手"等垂直场景目前**未见现成模板**，需要基于通用平台（百炼/Dify/Coze）自建。
