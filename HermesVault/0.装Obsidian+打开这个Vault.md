# 装 Obsidian + 打开这个 Vault(Windows)

> 小马写的给"第一次用 Obsidian"的主人。
> 全程 10 分钟,装完直接看到 wiki 渲染好的样子。

## 1. 下载 Obsidian

- 打开 https://obsidian.md/download
- 选 **Windows Installer (.exe)**
- 装的时候让它**全用户安装**(省去后面权限麻烦)

## 2. 第一次打开

装完双击 Obsidian 图标,会让你选 vault:

```
┌─────────────────────────────────────┐
│  Open folder as vault               │
│  Create new vault                   │  ← 选这个
└─────────────────────────────────────┘
```

## 3. 关键选择

| 项 | 怎么选 | 为什么 |
|---|---|---|
| Vault name | `HermesVault` | 跟文件夹名一致,以后小马好认 |
| Vault location | `E:\rhProject\HermesVault` | **直接点"Open"按钮选目录,不要手敲路径** |
| Vault type | **Local**(默认) | 不要选 "Obsidian Sync" / "Remotely" — 后面再开同步 |

⚠️ **重要**:路径一定要选到 `HermesVault` 这个**子目录**,不是 `E:\rhProject\`。
Obsidian 会把 `.obsidian/` 配置文件夹建在 vault 根。

## 4. 关安全模式,装插件

1. 左下角齿轮 ⚙️
2. 左侧选 **Community plugins** (第三方插件)
3. 顶上那个**关掉** "Restricted mode"
4. 点 **Browse** 按钮 → 跳到插件市场
5. 照 `8件套插件说明.md` 里的清单装

## 5. 验证(必做)

打开 `index.md`,应该看到:

- ✅ 顶部是 "Wiki Index" 标题
- ✅ 链接是蓝色(`[[SCHEMA]]` 这种),Ctrl+点击能跳转
- ✅ 左边 File Explorer 看到 `concepts/` `raw/` 等目录

## 6. 第一次写笔记

- 右键 `concepts/` → New note → 标题写 `test`
- 在笔记里粘:
  ```yaml
  ---
  title: test
  created: 2026-06-18
  updated: 2026-06-18
  type: concept
  tags: [test]
  sources: []
  confidence: medium
  ---
  ```
- 回到 `index.md`,粘这个查询:

  ````markdown
  ```dataview
  TABLE title, type
  FROM ""
  WHERE type = "concept"
  ```
  ````

- 能看到 `test` 那一行 → 整套搭成功 ✅
- 删掉 `test.md`,主人可以开始正式写了

## 7. 同步(可选)

| 方案 | 适合 | 怎么开 |
|---|---|---|
| **Obsidian Sync** | 简单,付费 | Settings → Sync → Login |
| **Git 同步** | 主人已经在 rhProject 里用 git,自然 | `.obsidian/workspace.json` 已经在 .gitignore 里,git status 不会乱报 |
| **iCloud / OneDrive** | 跨设备最方便 | 把 vault 移到 `C:\Users\RUHAI\iCloudDrive\` 或 OneDrive 目录,Obsidian 重新打开 |

> 主人已经在用 git + OneDrive,小马建议**先不上同步**,等攒到 30+ 页再开。

## 8. 踩坑速查

| 现象 | 解决 |
|---|---|
| 打开时"找不到 vault" | 路径里有中文? 改 `E:\rhProject\HermesVault`(全英文) |
| Dataview 没结果 | 重新打开 vault(改 frontmatter 后必须刷新) |
| Templater 没自动填日期 | 在 Templater 设置里把模板路径指到 vault 内 |
| 同步后两边内容不一样 | 立刻关掉 Obsidian Sync,改用 git,不要混 |
| 文件名乱(想改标题) | Obsidian 原生支持:右键 → Rename → 自动改所有引用 |
