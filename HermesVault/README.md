# HermesVault — 本地知识库

> Obsidian + LLM Wiki + Hermes 三件套的本地知识库。
> 不要直接编辑这里 — 让 Hermes(skill: `llm-wiki`)来整理,见 [[SCHEMA]]。

## 打开方式

- Obsidian:打开 `HermesVault/` 作为 vault
- 终端 / IDE:任意 markdown 编辑器都行(纯文本)

## 第一次用

看 `0.装Obsidian+打开这个Vault.md` → 10 分钟装好

## 目录速览

- `SCHEMA.md` — 规约,改之前必看
- `index.md` — 入口目录
- `log.md` — 改动流水
- `8件套插件说明.md` — Obsidian 必装插件
- `dataview示例.md` — Dataview + Templater 开箱用
- `raw/` — 原始材料(只读)
- `concepts/` — 概念页
- `entities/` — 实体页
- `comparisons/` — 横向对比
- `queries/` — 值得留的查询
- `_meta/` — 索引、归档

## git 状态

- `.obsidian/workspace.json` 等运行时状态在 .gitignore 里
- `.obsidian/app.json` 等配置在 git 里(跨机器同步)
- 写完 commit 一次就行
