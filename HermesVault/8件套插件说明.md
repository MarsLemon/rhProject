# Obsidian 8 件套 + 小马补 5 个

> 主人发的小红书链接小马抓不到(小红书私域短链需要 App 端登录)。
> 这份是社区公认的 8 件套 + 小马按主人工作流补的 5 个,主人照着装就行。
> 装完看一眼 Dataview / Templater 的**示例查询**,立刻能用。

## 0. 怎么装(以第 1 个为例)

1. Obsidian 打开 `HermesVault` 这个 vault
2. 左下角齿轮 ⚙️ → 第三方插件 → 关闭"安全模式" → "社区插件市场" → 搜索名字 → Install → Enable
3. 装完关掉 vault 再开,部分插件需要重启

---

## 第一梯队:必装(8 件套)

### 1. **Dataview** — 数据查询

让 markdown 文件的 frontmatter 字段可以查。像 Notion 的 database。

**怎么用**:在 markdown 任意位置写下面这段:

```dataview
TABLE title, type, updated
FROM ""
WHERE type = "concept"
SORT updated DESC
LIMIT 10
```

> 不写代码也行,有个配套插件 **Dataview(JS 查询)**,比基础 Dataview 更灵活。
> 小马建议**两个都装**:`dataview` + `dataviewjs` 不冲突。

**主页**: https://github.com/blacksmithgu/obsidian-dataview

### 2. **Templater** — 模板

新建笔记时自动填日期、文件名、调用变量。写日记/会议纪要的神器。

**示例模板**(在 Templater 设置里粘贴,模板名 `Concept`):

```markdown
---
title: <% tp.file.title %>
created: <% tp.date.now("YYYY-MM-DD") %>
updated: <% tp.date.now("YYYY-MM-DD") %>
type: concept
tags: []
sources: []
confidence: medium
---

# <% tp.file.title %>

## 一句话定义
_写下来这个概念是什么_

## 为什么重要
_主人(RUHAI)为什么关心_

## 关键事实
-

## 相关
-

## 来源
-

```

> 触发:右键文件夹 → Templater → Insert template → 选 `Concept`

### 3. **Excalidraw** — 手绘白板

架构图、流程图随手画。**输出是 Excalidraw 格式(.excalidraw.md)**,git diff 友好。

> 小马用 `excalidraw` skill 时输出的就是这种格式,直接能放进 Obsidian 看。

### 4. **Mind Map** — 大纲转脑图

把无序列表一键转成脑图。适合做 brainstorming 输出。

**用法**:`/mindmap` 触发(配合 Outliner 风格列表)

### 5. **Calendar** — 日历视图

左侧栏多一个日历,点日期能看到那天所有笔记。
**前提**:笔记文件名是 `YYYY-MM-DD-xxx.md` 格式(配合 Templater 自动)。

### 6. **Tasks** — 任务管理

- 写 `- [ ] 跟进小红书笔记` 在任何页面
- Tasks 插件会汇总到全局视图
- 支持 query 语法:`- [ ] #task 📅 2026-06-25 ⏫ 高优先级`

> 适合把 vault 当 GTD 工具用。

### 7. **QuickAdd** — 快速捕获

按 `Ctrl+P` → QuickAdd → 输入一句话 → 自动归档到 `inbox/` 文件夹。
**配合 Templater**:捕获同时自动套模板。

> 主人平时微信/小红书看到好东西,先 QuickAdd 扔到 inbox,小马定期消化。

### 8. **Kanban** — 看板

把 frontmatter 里 `status: todo` 的页面聚合成看板。
`todo` / `doing` / `done` 三列自动。

> 跟 Tasks 插件互补。Tasks 管细颗粒任务,Kanban 管项目状态。

## 第二梯队:小马补的 5 个(强推)

### 9. **Make.md** — 空间组织

把 vault 当 Notion 那样用:Space / Banner / 嵌套文件夹。
**配合 Dataview** 可以做"今日聚焦"工作台。

### 10. **Outliner** — 大纲优化

按住 Tab 缩进、Alt+↑↓ 排序、Enter 自动同级。**写作手感比原生好 2 倍**。

### 11. **Tag Wrangler** — 标签管理

重命名标签会**全局改完**,不像 Obsidian 原生得一个个改。
配合 SCHEMA 的 taxonomy 一起用,标签通胀问题彻底解决。

### 12. **Editor Width Slider** — 编辑器宽度

Ctrl+滚轮调编辑区宽度。**比改 CSS 简单 100 倍**。

### 13. **Shell Commands** — 跑命令

在 Obsidian 里面跑 `git status` / `python xxx.py` / 各种 CLI。
**适合 vault 里嵌脚本工作流** —— 比如让小马把每周总结脚本跑在 vault 里直接产出。
