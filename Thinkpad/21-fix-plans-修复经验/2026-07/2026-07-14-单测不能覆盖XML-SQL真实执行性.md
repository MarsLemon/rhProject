# 教训：单测不能覆盖 XML / SQL 真实执行性

## 一句话

**Mockito 单测是 mock mapper/service，**永远验证不了 MyBatis XML 的字段名、表名、JOIN 关系是否真的能在生产 DB 上跑通**。上线前必须有真实 DB 集成测试或人工 SQL 抽查。**

## 触发场景

- 新增 `<select>` / `<update>` / `<delete>` XML 节点
- XML 引用了**实体里没有的列名**
- XML 用了 `LEFT JOIN` 但 JOIN 列可能不在所有 DB 实例上存在
- 列名拼写错误（`chech_rules_json` vs `check_rules_json`）
- 表名错误（`el_plan` vs `el_plan_node`）

## 真实事故案例（2026-07-14 H3 修复）

| 项 | mock 单测结果 | 真实 DB 结果 |
|---|---|---|
| `PlanNodeMapper.selectImpactedByCourse` | ✅ 32/32 通过 | ❌ `Unknown column 'n.deleted' in 'where clause'` |
| SQL：`AND n.deleted = 0` | Mockito 直接返回 mock 数据，不查 DB | `PlanNode` 实体无 `deleted` 字段 → 列不存在 → 抛异常 |
| 接口 `PlanImpactedByCourseController` | ✅ 调用链路通 | ❌ 线上调用必爆 → 兜底返回空列表 → 弹窗功能 100% 失效 |

**根因**：单测用 `@Mock private PlanNodeMapper`，所有 `selectImpactedByCourse` 调用都被 mock 拦截，**根本没有执行到 XML 解析层**。

## 反模式 vs 正模式

### ❌ 反模式：mock mapper → 觉得"测试过了"

```java
@ExtendWith(MockitoExtension.class)
class FooServiceTest {
    @Mock private FooMapper fooMapper;
    @InjectMocks private FooService service;

    @Test
    void test() {
        when(fooMapper.select(any())).thenReturn(List.of(...));
        service.execute();  // 通过!但 XML 可能有 10 处拼写错误
    }
}
```

### ✅ 正模式 1：XML 字段名与实体对齐自检

新增 XML `<select>` 前，**必须 grep 实体确认字段真存在**：

```bash
# 检查 XML 用的列名是否在实体里
grep -E "@TableField|@TableId" Foo.java

# 检查表名是否与 @TableName 一致
grep "@TableName" Foo.java
```

### ✅ 正模式 2：测试用真实 DB（推荐）

- Testcontainers 起 MySQL 容器 → 跑 schema → 跑 XML
- 本地维护 dev DB → CI 跑连通性测试
- 至少写一条针对真实 SQL 的 smoke test

### ✅ 正模式 3：上线前人工 SQL 抽查（兜底）

```sql
-- 把 XML 里的 SQL 拼出来,在生产影子表跑一次
SELECT n.plan_id, p.title, n.update_time, MD5(n.check_rules_json)
FROM el_plan_node n LEFT JOIN el_plan p ON p.id = n.plan_id
WHERE n.node_type = 'course' AND n.ref_id = 'test-cid';
```

## 必须做的自检清单（XML 改动后）

- [ ] 所有 `WHERE` / `JOIN ON` 用的列名都在对应实体的 `@TableField` 里
- [ ] 所有表名都在对应实体的 `@TableName` 里
- [ ] 单测跑过 ≠ XML 可执行，必须有集成测试或人工 SQL 抽查
- [ ] 上线后必须有第一次真实 DB 调用的冒烟检查（哪怕只查一条）

## 红线

**禁止**：新增 XML 后只跑 `mvn test` 就认为"可发布"

**禁止**：mock mapper 视为"集成测试"

**强制**：任何 XML 改动，diff 自检 + 字段名 grep + 上线后第一次人工抽查
