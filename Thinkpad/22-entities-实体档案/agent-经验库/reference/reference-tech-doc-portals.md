# 常用技术文档入口(2026-06-26 用户给出)

> 用户主动给出的 6 个网站合集,按编号索引。改 UI / 接入 AI / 写前端三剑客 / 学 Java 时直接打开对应编号。

| 编号 | 名称 | URL | 用途 | 关联项目 |
|---|---|---|---|---|
| 1 | Element UI (v2) | https://element.eleme.cn/#/zh-CN/component | Vue 2.x 桌面端 UI 组件参考 | [[wk-train-center-ui]] |
| 2 | Vant 4 | https://vant4.ylhtest.com/#/zh-CN | 移动端 UI 组件参考(Vue 3) | 移动端/H5 |
| 3 | Element Plus | https://element-plus.org/zh-CN/component | Vue 3.x 桌面端 UI 组件参考 | [[wk-train-center-ui-v3]] |
| 4 | 阿里云百炼 API | https://bailian.console.aliyun.com/cn-beijing/?tab=api#/api/?type=app | AI 应用/模型 API 文档 | [reference-bailian-file-size-limits](./reference-bailian-file-size-limits.md) |
| 5 | MDN Web Docs | https://developer.mozilla.org/zh-CN/ | HTML/CSS/JS 权威 wiki | 所有前端 |
| 6 | bugstack(Java 学习博客) | https://bugstack.cn/md/road-map/road-map.html | Java 资料/DDD/源码分析参考 | [[wk-train-center-service]] |

**Why:** 这些是用户日常工作高频访问的权威资料源,免去每次重新搜索/猜版本;Element UI(2) vs Element Plus(3) 容易混,编号 1/3 必须明确区分 Vue 2 / Vue 3 时代。

**How to apply:**
- 写 Vue 2 桌面端组件 → 看 1(element.eleme.cn)
- 写 Vue 3 桌面端组件 → 看 3(element-plus.org)
- 写移动端 H5 组件 → 看 2(vant4)
- 调百炼 AI 接口 → 看 4(配合 [reference-bailian-file-size-limits](./reference-bailian-file-size-limits.md) 的上传限制表)
- 前端三剑客 API 不确定 → 查 5(MDN 中文版)
- Java/源码/设计模式学习 → 看 6(bugstack)

**注意:**
- 编号 2 的 URL 是 `vant4.ylhtest.com`(非官方 `vant-ui.github.io`),如有变动优先信官方
- 编号 1 的 element.eleme.cn 仍是 Vue 2 时代的官方镜像,Element Plus 已迁到 element-plus.org
