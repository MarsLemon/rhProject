## 1. 调研背景与目标

### 1.1 调研背景

随着短视频与中长视频内容生态的爆发，企业内训、自媒体创作、商业营销、教学课件等场景对**公网视频资源**的引用与二次创作需求持续增长。然而：

- **著作权法**对视频作品的保护力度在 2020 年修法后显著加强；
- **平台规则**日益收紧，未授权搬运、下载传播行为被大规模整治；
- **二次创作**（解说、混剪、翻译、切片）在法律上**默认属于侵权**，仅在符合"合理使用"条件时方可免责；
- **商业使用**（付费课程、广告投放、付费会员内容）面临最严格的版权审查。

**核心矛盾**：公众普遍存在"视频看得见就能用"的认知误区，与现行法律严格保护形成冲突。

### 1.2 调研目标

1. 梳理**中国著作权法**对视频侵权的判定框架与"合理使用"边界；
2. 横向对比**主流平台**的版权规则，明确"站内观看 / 跨平台搬运 / 二次创作 / 商业使用"的法律边界；
3. 整理**合法可用的免费视频资源入口**地图（按风险从低到高）；
4. 给出**风险矩阵**与**针对不同身份的使用方案**；
5. 提供**可执行的 5 分钟自查清单**与**待核实事项清单**。

### 1.3 调研方法

- 法律框架：基于《中华人民共和国著作权法》（2020 修订）通识性条款；
- 平台规则：基于各平台公开用户协议、社区规范的通识性认知；
- 资源入口：基于通识性的 CC 协议生态与已知免费素材库；
- **数据验证缺失**：本报告未完成网络原文核验（详见第八章）。

## 2. 法律框架：视频侵权的判定逻辑

### 2.1 三步判定法

判断一个使用行为是否构成侵权，按以下三步走：

**Step 1：是否属于"作品"？**
- 视频一般属于"视听作品"（《著作权法》2020 修订后新分类），受法律保护。
- 例外：纯事实记录（如监控录像、纯新闻事件记录）可能不构成独创性表达，但实务中**几乎所有 UGC 视频都默认是作品**。

**Step 2：是否经过权利人许可？**
- 许可的来源可以是：**明示许可**（如创作共用 CC 协议）、**默示许可**（如平台协议允许的行为）、**法定许可**（极少适用于视频）、**合理使用**（下文详述）。
- **未明示允许 = 默认禁止**。这是版权法的基本原则。

**Step 3：是否落入"合理使用"例外？**
- 这是唯一能"不许可就用"的口子，但门槛很高。

### 2.2 合理使用（《著作权法》第 24 条）

《著作权法》共列出 13 种合理使用情形，与视频最相关的有以下几项：

| 编号 | 情形 | 视频场景举例 | 关键边界 |
|---|---|---|---|
| 第 1 项 | 个人使用 | 自己存着看 | **不得传播**。上传任何平台、转发同事均构成侵权 |
| 第 2 项 | 适当引用 | 教学课件嵌入 5 秒片段 | 引用比例合理 + 注明出处 + 不构成实质性替代 |
| 第 3 项 | 新闻报道 | 报道中引用 3 秒画面 | 不可避免 + 注明出处 |
| 第 4 项 | 教学 / 科研 | 课堂播放、慕课 | 限于教学 / 科研人员 + 不得出版发行 |
| 第 5 项 | 公务使用 | 政府部门内部 | 范围极窄 |
| 第 9 项 | 公共场所再现 | 美术馆展品被拍进视频 | 主体是美术 / 摄影 / 图形作品 |

**关键边界提示**：
- 教学合理使用**不等于"教学课件可随便用视频"**。把视频完整嵌入可下载的 PDF / PPT 发给学员永久保存 = 超出教学合理使用范围。
- "**标注出处 ≠ 免责**"。标注是合理使用的加分项，不是免责符。
- "**只用了几秒 ≠ 一定不侵权**"。判断是"引用比例合理 + 不构成实质性替代"。几秒也可能侵权（如果是核心情节 / 画面）。

### 2.3 二次创作的法律定性

二次创作（鬼畜 / 混剪 / 解说 / 翻译 / 切片）在法律上**默认是侵权**。仅当同时满足以下条件时，才可能主张合理使用：

1. 属于"适当引用"或"评论 / 研究目的"；
2. 形成了**新的独创性表达**（不是简单搬运、简单翻译、简单切片）；
3. **未对原作市场造成实质性替代**。

**高频踩坑**：
- **搬运号**：直接搬运他人视频 = 100% 侵权。
- **纯翻译号**：仅翻译字幕、不增加新表达 = 侵权。
- **纯切片号**：把长视频切成短视频再发 = 侵权（构成实质性替代）。
- **解说号**：加入自己的评论 / 分析 / 笑点 / 剪辑节奏的，可能落入合理使用边界，但**仍需逐案判断**。

### 2.4 平台协议授权 vs 法律授权

这是**最容易被忽略的关键区分**：

- B 站、抖音、小红书的**用户协议**授予你的是**在该平台内**使用视频的权利（看、转、评、赞）。
- **不**授予你下载后到其他平台、线下场景、二次发行的权利。
- **跨平台搬运 = 双重侵权**：违反原平台协议 + 著作权侵权。

## 3. 主流平台规则横向对比

### 3.1 横向对照表

| 平台 | 站内转赞评 | 官方下载 | 跨平台搬运 | 二次创作 | 商业使用 |
|---|---|---|---|---|---|
| **B 站（哔哩哔哩）** | ✅ | ❌ 协议禁止未授权下载传播 | ❌ 需权利人授权 | 创作者激励计划有授权机制；普通二创需自查 | 需权利人授权 |
| **抖音** | ✅ | ⚠️ 仅限官方"保存到本地"功能；不得传播 | ❌ | 需自查合理使用 | 需授权 |
| **小红书** | ✅ | ❌ | ❌ | 需注明出处 + 自查合理使用 | 需授权 |
| **微信视频号 / 公众号** | ✅ | ❌ 协议禁止 | ❌ | 腾讯有原创保护机制 | 需授权 |
| **YouTube** | ✅ | 官方提供离线下载（YouTube Premium） | ❌ 需看创作者声明 | CC BY 视频可以 | 需看创作者声明 |
| **TED / TED-Ed** | ✅ | ❌ 需看视频说明 | ❌ | CC BY-NC-ND 4.0（非商用、不得衍生） | 商用需联系 |
| **西瓜视频** | ✅ | ❌ | ❌ | 头条系有"授权搬运"机制 | 视情况 |
| **快手** | ✅ | ❌ | ❌ | 需自查 | 需授权 |

### 3.2 通用铁律（适用于所有平台）

1. **未明示允许转载 = 默认禁止**。
2. **创作者主动声明"欢迎转载"** = 仍需看清声明里的具体条件（是否注明出处、是否商用、是否要求联系）。
3. **平台上的"分享"按钮 ≠ 法律授权**，只是**站内**分享。
4. **截图 / 录屏 / 爬虫 / 第三方下载工具**都属"技术手段获取"，是否侵权看**后续使用**，不在获取方式本身。
5. **创作者本人 = 著作权人**，创作者对自己的作品享有完整权利，平台不替你授权。

### 3.3 平台版权治理趋势

- **2023-2024**：B 站、抖音、快手等平台对未授权搬运号进行大规模清理；
- **2024-**：腾讯、爱奇艺、优酷、芒果 TV 加大版权维权力度，长视频片段搬运风险陡增；
- **2025-**：AIGC 与深度伪造相关法律风险上升，**使用他人素材训练 AI / 生成衍生视频**已成新风险点。

## 4. 合法的免费视频资源入口地图

按风险从低到高，分五个梯队。

### 4.1 🟢 第一梯队：明确可商用、自有 / CC 协议

| 站点 | 协议 | 类型 | 备注 |
|---|---|---|---|
| **Pexels Videos** | 自有协议（免费商用） | 实拍短片 | **无需署名** |
| **Pixabay Videos** | 自有协议（免费商用） | 实拍 + 动画 | 不可单独售卖 |
| **Coverr** | 自有协议 | 实拍 | 适合背景视频 |
| **Mixkit** | 自有协议 | 高质量实拍 | 分免费 / 付费两档 |
| **Videvo** | CC BY 3.0 / CC 0 / 自有 | 类型较杂 | 注意看每条的具体协议 |
| **Life of Vids** | CC 0 | 风景 / 生活 | |
| **Dareful** | CC BY 4.0 | 4K 风景 | 需署名 |
| **Mazwai** | CC BY 3.0 | 电影感短片 | 需署名 |

### 4.2 🟡 第二梯队：CC 协议 / 开放授权（需逐条核条款）

- **Vimeo Creative Commons** — 创作者主动选 CC 协议的视频
- **Internet Archive** — 大量历史影像，协议各异，逐条核
- **NASA 影像库（images.nasa.gov）** — **美国政府作品**，**全球公有领域**（**注意仅限 NASA 自家**；ESA、中国国家航天局、JAXA 等规则不同）
- **CC Search（search.creativecommons.org）** — 聚合搜索
- **Openverse（openverse.org）** — CC 协议聚合
- **Wikimedia Commons** — 多为 CC 协议，逐条核

### 4.3 🟡 第三梯队：政府 / 官方 / 媒体（多为"可引用，不可商用"）

- **中国国家媒体**：央视新闻、新华社、人民日报的视频，**官方明确可用于新闻报道**；商用需走授权。
- **地方政府 / 部门官网**发布的视频（新闻发布会、政策解读）—— 通常**可新闻引用**，**不直接可商用**。
- **高校公开课**：MOOC 平台视频**几乎全部禁止未授权转载**（清华学堂在线、中国大学 MOOC 等都明确）。B 站上一些高校官方号授权转载的，可以看账号说明。
- **TED / TED-Ed** —— 创用 CC BY-NC-ND 4.0（**非商用、不得衍生**），商用要联系。

### 4.4 🟠 第四梯队：可参考但不直接用

- **YouTube / B 站 / 抖音**：通过站内嵌入 / 分享链接在自家平台展示（**属于平台内分享**，合规）；**不能下载下来再用**。
- **新闻聚合**：把新闻链接嵌入自己页面 = 通常 OK；截图 / 截屏当素材 = 看后续用途。

### 4.5 🔴 第五梯队：高风险，绝对不要碰

- 影视剧、综艺、动漫、纪录片片段（爱优腾芒 B 站大会员内容）
- 商业 MV、演唱会、体育赛事
- 任何"未署名 / 找不到原作者"的素材
- 任何声称"免费商用"的小网站（先核协议再信）

## 5. 风险矩阵：使用场景 × 风险等级

| 你的使用场景 | 直接搬运 | 二次创作（评论 / 解说） | 嵌入官方链接 |

| **企业内部培训**（不外传） | 🟠 中风险 | 🟢 低 | 🟢 低 |
| **公司公众号 / 官网发文** | 🔴 高 | 🟡 中（注明出处 + 短引用） | 🟢 低 |
| **公司付费课程 / 付费会员内容** | 🔴 高 | 🔴 高（仍可能构成替代） | 🟡 中 |
| **公开演讲 / 发布会** | 🟠 中 | 🟡 中 | 🟢 低 |
| **抖音 / 小红书自媒体账号** | 🔴 高 | 🟡 中 | 🟢 低 |

**结论**：
- 越**对外传播**、越**商业化**、越**完整呈现**，风险越高。

- **"二次创作"** 仅在具备**新表达 + 不构成替代**时才可能落入合理使用。

## 6. 针对不同身份的使用方案

### 6.1 身份 A：企业内训 / HR / 培训部门

✅ **优先用**：Pexels / Pixabay / Coverr / Mixkit（CC 协议，可商用）
✅ **可引用**：央视 / 新华社视频 + **注明出处 + 仅新闻性引用**
❌ **不要用**：B 站抖音下载的"网红课"、盗版剧片段

### 6.2 身份 B：内容创作者 / 自媒体

✅ **优先用**：CC 协议素材 + 官方授权素材 + 自拍
✅ **可二创**：明确"创作者声明欢迎二创"的视频，**仍需注明出处 + 平台标识水印**
❌ **不要用**：搬运 / 纯切片 / 纯翻译

### 6.3 身份 C：教师 / 培训师

✅ **课堂播放**：直接用 B 站 / YouTube / 官方平台播放（**教学合理使用**）
✅ **课件嵌入**：短片段 + 注明来源 + 不超过必要比例
❌ **不要**：把视频完整嵌入可下载的 PDF / PPT 发给学员永久保存

### 6.4 身份 D：商业项目（付费产品 / 广告）

✅ **必须用**：明确商用授权的素材（CC 0 / Pexels 协议 / 自购版权）
✅ **必须做**：签授权书 / 留存授权凭证
❌ **不要**：用任何"应该没问题"的模糊来源

## 7. 5 分钟自查清单

使用任何公网视频前，**问自己这 5 个问题**：

1. **原作者是谁？** 找不到 = 默认不用
2. **协议 / 声明是什么？** CC / 商用授权 / 仅供观看 / 欢迎转载？
3. **我用它来做什么？** 内部 / 对外 / 商业 / 教学？
4. **我用了多少？** 几秒 vs 整段，核心情节 vs 边角
5. **我标了出处吗？**（虽然不能免责，但能减轻）

**5 个全过且答"是"** → 大概率安全
**任一答"否 / 不确定"** → 不碰

## 9. 总结与建议

### 9.1 核心结论

1. **视频侵权的判定是三层叠加的**：法律层 + 平台层 + 商业使用层。每一层都要过。
2. **合理使用是窄口**，不能套用到日常转载、二创、搬运场景。
3. **跨平台搬运 = 双重侵权**（违反原平台协议 + 著作权侵权），是最常见也最容易踩的坑。
4. **合法免费资源是充足的**（Pexels / Pixabay / NASA 等），企业 / 创作者没有"必须用盗版"的必要。
5. **标注出处 ≠ 免责**，但能作为减轻情节。
6. **AIGC 时代的新风险**：用他人素材训练 AI / 生成衍生视频，正在成为新的侵权高发区。

### 9.2 给使用方的建议

| 建议 | 适用对象 |
|---|---|
| **建立内部"视频素材 SOP"**：明确"哪类来源可以用、哪类不行、引用多少合适、是否签授权" | 企业内训 / 营销 / 内容团队 |
| **商业项目必须留存授权凭证**：口头许可不算数 | 法务、采购、内容运营 |
| **教学场景优先用"播放链接 + 嵌入"**，不下载下来 | 教师 / 培训师 |
| **二创务必加自己的新表达**，且**注明出处** | 自媒体 / 内容创作者 |
| **看到"免费商用"小网站先核协议再信** | 全员 |

### 9.3 后续建议动作

1. **法务复核**：本报告涉及的法律条文、平台协议由法务 / 版权岗做一次复核（建议优先级：高）；
2. **资源站实测**：从第一梯队选 2-3 个站点做实际下载与协议核对（建议优先级：中）；
3. **内部培训**：把本报告的"风险矩阵 + 自查清单"作为内部培训内容（建议优先级：中）；
4. **建立素材库**：基于 Pexels / Pixabay 等站点建立**内部合规视频素材库**，减少每次临时找素材的风险（建议优先级：低，长期价值高）；
5. **定期更新**：建议每半年复核一次本报告（法律与平台规则都在持续变化）。
