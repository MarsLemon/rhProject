根目录作为 VS Code workspace 聚合层，将三个互不依赖的子域并列组织：
- `Thinkpad/`：Obsidian Vault（本地知识库），按数字前缀目录组织原始材料、消化笔记、实体档案与修复经验。
- `Backend/`、`Frontend/`：后端与前端子项目，各自独立但共享根级 `.qoder/rules/` 规范套件与 `.claude/skills/` 技能框架。
- `.qoder/rules/`：集中式 AI 编码规范（core/architecture/process/quality/sdlc），由 `AGENTS.md` 以 trigger: always/manual 机制路由到不同任务类型（Java/Spring Boot、Vue/Angular、测试、运维等）。
- `.claude/skills/`：20 个 superpowers-zh 技能，通过 `CLAUDE.md` 声明在 Claude Code/OpenClaw/Cursor 中按需加载。
- `.mcp.json`、`.code-workspace`：MCP 服务器与工作区配置，使各子项目在同一个 IDE 会话中共享同一套 AI 上下文。
根级不承载业务代码，仅承担「规范分发 + 技能编排 + 工作区装配」职责。
