## 架构差异

### 路由重构
- V2：10 个模块文件分离（course/exam/plan/repo/notice/ucenter 等）
- V3：5 文件，`student.ts` 合并学员路由（248 行），`async-routes.ts` 处理动态路由，`guards/` 独立守卫模块
- 管理端路由由后端动态下发

### API 层重构
- V2：扁平结构 `api/sys/user/user.js`
- V3：分域结构 `api/admin/` + `api/client/` + `api/common/`
- V3 新增 `factory.ts`（327 行）统一请求工厂 + `types.ts`（91 行）全局类型

### 状态管理
- V2：Vuex 7 模块（app/user/permission/settings/tagsView/knowledge）
- V3：Pinia 7 模块 + 新增 `ai.ts`（510 行）AI 状态独立管理

### 工具函数重组
- V2：32 个扁平文件
- V3：46 个文件，按域分目录（ai/auth/common/dom/echarts/format/image/index/log/math/notification/storage/upload/validate）
