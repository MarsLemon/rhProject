# 厂家字典 接口对接文档

> 版本：v1.0 | 日期：2026-09-03 | 对应后端：`manufacturer` 模块（厂家字典，R-03：型号-厂家多对多的全局字典；R-04：价格与厂家无关）
>
> 面向前端/AI 辅助对接：每个接口给出**可复制的请求/响应 JSON 示例**。通用约定（响应包络、鉴权、环境）见 [README.md](../README.md)。
>
> **Postman 集合**：[manufacturer.postman_collection.json](./manufacturer.postman_collection.json) —— 6 个请求（后台 5 + 前台 1）、响应示例、内置 `code=00000000` 断言、预置 Authorization 裸 token；导入后在集合 Variables 中按环境修改 `baseUrl`（默认 `http://localhost:8031`）。

---

## 1. 接口总览

| # | 接口 | 方法 | 路径 | 用途 | 权限点 |
|---|------|------|------|------|--------|
| 1 | 厂家列表 | GET | `/web/manufacturer/list` | 后台字典维护视图（含停用） | `pricing:web:manufacturer:list` |
| 2 | 新增厂家 | POST | `/web/manufacturer/add` | 新增，编码系统生成 | `pricing:web:manufacturer:add` |
| 3 | 重命名 | PUT | `/web/manufacturer/rename` | 改中/英文名 | `pricing:web:manufacturer:rename` |
| 4 | 启用/停用 | PUT | `/web/manufacturer/change-status` | 控制下拉可见性 | `pricing:web:manufacturer:change-status` |
| 5 | 删除厂家 | GET | `/web/manufacturer/delete/{id}` | 逻辑删除 | `pricing:web:manufacturer:delete` |
| 6 | 启用厂家列表 | GET | `/web/portal/manufacturer/list-enabled` | 型号维护多选 / 询价页下拉 | 登录态即可 |

## 2. 码表与公共字段说明

### 2.1 status 业务状态

| 码 | 含义 | 表现 |
|----|------|------|
| 1 | 启用 | 出现在启用厂家列表（`/list-enabled`） |
| 0 | 停用 | 从启用列表消失；后台 `/list` 仍可见（前端置灰）；可重新启用 |

### 2.2 厂家编码 code（只读，系统生成）

- 格式：`M` + 4 位递增序号（M0001、M0002…）；
- 新增后立即返回，**前端不可手填、不可编辑**；
- 删除后序号不复用（删 M0002，下个新增仍是 M0003）。

### 2.3 名称约束

- 中文名必填 1~100 字，**精确唯一**（区分大小写），新增与重命名均校验；
- 英文名选填 ≤200 字，不查重；中英文名共同参与列表关键词过滤。

## 3. 后台接口明细

### 3.1 厂家列表（含停用，关键词过滤）

```
GET /web/manufacturer/list?keyword={keyword}
```

**入参**：

| 字段 | 位置 | 必填 | 说明 |
|------|------|------|------|
| keyword | query | 否 | 匹配 编码/中文名/英文名（不区分大小写），为空返回全量 |

示例：`GET /web/manufacturer/list?keyword=man`

**响应 data**：`ManufacturerVo[]`（平铺列表，按编码升序）：

```json
[
  {
    "id": 1,
    "code": "M0001",
    "name": "HD HYUNDAI",
    "nameEn": "HYUNDAI HEAVY INDUSTRIES",
    "status": 1,
    "updateTime": "2026/09/03 10:30:00",
    "updateBy": "张三"
  },
  {
    "id": 2,
    "code": "M0002",
    "name": "MAN B&W",
    "nameEn": "MAN B&W",
    "status": 0,
    "updateTime": "2026/09/03 11:00:00",
    "updateBy": "张三"
  }
]
```

---

### 3.2 新增厂家

```
POST /web/manufacturer/add
Content-Type: application/json
```

**入参**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 中文名，1~100 字，精确唯一 |
| nameEn | string | 否 | 英文名，≤200 字 |

```json
{ "name": "CSSC", "nameEn": "CHINA STATE SHIPBUILDING" }
```

**响应 data**（`ManufacturerAddVo`，编码已生成，可直接回显列表）：

```json
{ "id": 3, "code": "M0003" }
```

**失败场景**：中文名重复（803120202）、编码冲突（803120201，并发极小概率，提示刷新重试）。

---

### 3.3 重命名

```
PUT /web/manufacturer/rename
```

```json
{ "id": 2, "name": "MAN Energy Solutions", "nameEn": "MAN ENERGY SOLUTIONS" }
```

**响应 data**：`null`（code=00000000 即成功）。

**约束**：仅中英文名可改；name 必填且不得与其他厂家重复；nameEn 传空字符串/不传即清空英文名；编码不可改。

---

### 3.4 启用 / 停用

```
PUT /web/manufacturer/change-status
```

```json
{ "id": 2, "status": 0 }
```

**响应 data**：`null`。

**约束**：status 仅允许 0/1；停用后从 `/list-enabled` 消失（型号维护下拉、询价页不再可选），已被型号关联的历史关系不受影响；可随时重新启用。

---

### 3.5 删除厂家

```
GET /web/manufacturer/delete/{id}
```

示例：`GET /web/manufacturer/delete/3`

**响应 data**：`null`。

**失败场景**：厂家不存在（803120200）。

**重要提示**：「被型号关联不可删」校验待型号模块落地后补充（当前版本删除前请人工确认无型号引用该厂家）。删除为逻辑删除，确认弹窗必配。

## 4. 前台接口明细

### 4.1 启用厂家列表

```
GET /web/portal/manufacturer/list-enabled
```

**响应 data**：`PortalManufacturerVo[]`（仅启用，按中文名升序，**无状态/操作人字段**）：

```json
[
  { "id": 1, "code": "M0001", "name": "HD HYUNDAI", "nameEn": "HYUNDAI HEAVY INDUSTRIES" },
  { "id": 3, "code": "M0003", "name": "CSSC", "nameEn": "CHINA STATE SHIPBUILDING" }
]
```

**使用方**：后台型号维护「制造厂家」多选、询价页选型号后的厂家下拉（R-03/R-04：厂家列表由型号决定默认选中，价格与厂家无关）。

## 5. 错误码表（本模块）

| code | 场景 | 前端处理建议 |
|------|------|------------|
| 00000000 | 成功 | — |
| 803120200 | 厂家不存在或已删除 | 刷新列表 |
| 803120201 | 厂家编码已存在（并发冲突） | 提示「请刷新后重试」 |
| 803120202 | 中文名已存在 | 表单行内提示，聚焦名称输入框 |
| 803120203 | status 取值非法 | 前端固定 0/1，正常不会触发 |

其余非 00000000 的 code 统一 toast `msg` 文案。

## 6. 典型对接流程

**后台字典维护卡片**（参照 demo vendors 卡片）：

```
进入页面 → GET /list 渲染表格（停用置灰）
  ├─ 新增输入框（Enter 连续录入） → POST /add（重名 803120202 行内提示）
  ├─ 行内编辑名称失焦 → PUT /rename
  ├─ 置灰开关 → PUT /change-status
  └─ 删除（确认弹窗） → GET /delete/{id}
每次写操作成功后 → GET /list 刷新列表
```

**型号维护页 / 询价页**：进入时 `GET /web/portal/manufacturer/list-enabled` 拉取下拉数据源（无需鉴权配置之外的额外处理）。
