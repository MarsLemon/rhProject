## 2. 码表与公共字段说明

### 2.1 status 业务状态

| 码 | 含义 | 表现 |
|----|------|------|
| 1 | 启用 | 出现在 by-equipment / list-enabled(前提:父设备与父分类都启用) |
| 0 | 停用 | 从前台接口不可见;后台 `/list` 仍可见(前端置灰);可重新启用 |

### 2.2 型号编码 code(只读,系统生成)

- 格式:`MOD` + 4 位序号(左补零),如 `MOD0001`、`MOD0002`;
- 新增后立即返回,**前端不可手填、不可编辑**(IN-NAM-01);
- 删除后序号不复用(取现存最大 +1,防外部引用漂移)。

### 2.3 缸数 cylinderCount(R-05/D3)

- 必填,整数范围 **1~20**;
- 类型属性,选型号自动带出只读;本期按必填处理(自定义型号允许手填)。

### 2.4 关联厂家 manufacturerLinks

- **至少一个**(BR-MOD-09 / IN-MOD-12),`@NotEmpty` 强制;
- 每项含 `manufacturerId / isLicense / sortOrder`;
  - `isLicense`:1=授权生产 0=自有(默认 0);
  - `sortOrder`:升序展示排序,默认 99=置后。

### 2.5 默认厂家 defaultManufacturerId(IN-EQ-04 / IN-MOD-11)

- 可空;为空时取关联集合中 `sortOrder` ASC 第一家;
- 非空时**必须 ∈ 当前关联集合**,否则 803120411 拒绝。

### 2.6 is_license 授权生产标记

| 码 | 含义 |
|----|------|
| 1 | 授权生产(厂家为型号授权代工方) |
| 0 | 自有(厂家为型号自有生产方,默认值) |

### 2.7 /list groupBy 字段

| 取值 | 返回结构 |
|------|---------|
| `equipment`(或 `Equipment`) | `ModelTreeNodeVo[]`,每项含 `{id,code,name,models[]}` |
| 空 / 其他 | `ModelVo[]` 扁平数组,按 code 升序 |

## 3. 后台接口明细

### 3.1 新增型号

```
POST /web/model/add
```

**请求体**:

```json
{
  "equipmentId": 10,
  "defaultManufacturerId": 1,
  "name": "6S60MC-C",
  "nameEn": "Main Engine",
  "mark": "C9.7",
  "cylinderCount": 6,
  "powerKw": 12000.50,
  "boreMm": 460,
  "manufacturerLinks": [
    { "manufacturerId": 1, "isLicense": 0, "sortOrder": 50 },
    { "manufacturerId": 2, "isLicense": 1, "sortOrder": 99 }
  ]
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| equipmentId | 是 | 所属设备 id;校验存在、未删除、启用(803120402/403) |
| defaultManufacturerId | 否 | 默认厂家 id;∈ manufacturerLinks 集合(803120411) |
| name | 是 | 中文名,1~100 字,同设备下精确唯一(803120410) |
| nameEn | 否 | 英文名,≤200 字 |
| mark | 否 | mark/版本号,≤50 字 |
| cylinderCount | 是 | 缸数,1~20 整数(803120404) |
| powerKw | 否 | 功率 kW,≥0(803120405) |
| boreMm | 否 | 缸径 mm,≥0(803120406) |
| manufacturerLinks | 是 | 关联厂家集合,≥1 项(803120412) |

**响应 data**:

```json
{ "id": 1, "code": "MOD0001" }
```

---

### 3.2 重命名/改规格

```
PUT /web/model/rename
```

**请求体**:

```json
{
  "id": 1,
  "name": "6S60MC-C-MarkII",
  "nameEn": "Main Engine Mark II",
  "cylinderCount": 6,
  "mark": "C9.8",
  "powerKw": 13500.00,
  "boreMm": 460
}
```

> code 与 equipmentId 不可改;新中文名不得与同设备下其他型号重复。

**响应 data**:`null`

---

### 3.3 切换归属设备

```
PUT /web/model/change-equipment
```

**请求体**:

```json
{ "id": 1, "equipmentId": 20 }
```

> 若原默认厂家不在新设备下关联集合,自动重置为剩余关联排序第一,响应 data 含重置后的 `defaultManufacturerId`。

**响应 data**:`ModelDetailVo`(同 §3.7 详情接口)

---

### 3.4 启用/停用

```
PUT /web/model/change-status
```

**请求体**:

```json
{ "id": 1, "status": 0 }
```

| 字段 | 必填 | 说明 |
|------|------|------|
| id | 是 | 型号 id |
| status | 是 | 1 启用 / 0 停用,仅允许 0/1(803120407) |

**响应 data**:`null`

---

### 3.5 增量更新厂家关联

```
PUT /web/model/manufacturers
```

**请求体**(完整列表,后端 diff 处理):

```json
{
  "id": 1,
  "defaultManufacturerId": 2,
  "manufacturerLinks": [
    { "manufacturerId": 1, "isLicense": 0, "sortOrder": 50 },
    { "manufacturerId": 2, "isLicense": 1, "sortOrder": 10 },
    { "manufacturerId": 4, "isLicense": 0, "sortOrder": 99 }
  ]
}
```

> 与数据库当前关联对比:新增项 `batchSave`;移除项 `batchDeleteByModelIdAndManufacturerIds`;默认厂家变化时复用 `changeEquipment(equipmentId, defaultManufacturerId)` 更新字段。

**响应 data**:`null`

## 4. 前台接口明细(无细粒度权限点,登录态即可)

### 4.1 按设备查询启用型号(询价页型号下拉)

```
GET /web/portal/model/by-equipment/{equipmentId}
```

**响应 data**:`PortalModelVo[]`(按 code 升序)

```json
[
  {
    "id": 1,
    "code": "MOD0001",
    "name": "6S60MC-C",
    "nameEn": "Main Engine",
    "cylinderCount": 6,
    "powerKw": 12000.50,
    "boreMm": 460,
    "equipmentId": 10,
    "defaultManufacturerId": 1
  }
]
```

> 父设备不存在/已删除/已停用 → 返空集;父分类停用 → 返空集(IN-MOD-13 / BR-MOD-11 前台可见性约定,前端不弹错)。

---

### 4.2 全量启用型号(型号与厂家联动供询价 R-04)

```
GET /web/portal/model/list-enabled
```

**响应 data**:同 §4.1,包含全量启用型号(按 code 升序)。

---

### 4.3 按设备+厂家查询启用型号(询价页选厂家后联动 R-03/R-04)

```
GET /web/portal/model/by-equipment-and-vendor?equipmentId=10&manufacturerId=1
```

**查询参数**:

| 参数 | 必填 | 说明 |
|------|------|------|
| equipmentId | 是 | 设备 id |
| manufacturerId | 是 | 厂家 id |

**响应 data**:`PortalModelVo[]` —— 该设备下与指定厂家关联的启用型号(按 code 升序)。

> 父设备停用/不存在/已删除 → 返空集;父分类停用 → 返空集。

## 5. 错误码表(8031204xx)

| code | 含义 | 触发场景 |
|------|------|---------|
| `803120400` | 型号不存在或已删除 | rename/changeStatus/changeEquipment/delete 时 id 不存在 |
| `803120401` | 型号编码已存在 | uk_code 兜底 / 应用层预校验 |
| `803120402` | 父设备不存在或已删除 | addModel 时 getEquipmentById 返回 null |
| `803120403` | 父设备已停用 | addModel 时父设备 status=0 |
| `803120404` | 缸数非法(非 1~20 整数) | cylinderCount 校验 |
| `803120405` | 功率非法(负数) | powerKw < 0 |
| `803120406` | 缸径非法(负数) | boreMm < 0 |
| `803120407` | 型号状态取值非法 | status 非 0/1 |
| `803120408` | 设备被型号引用,删除设备被拒 | **跨模块补账 #1**(设备 BR-EQ-05 落地) |
| `803120409` | 厂家被型号引用,删除厂家被拒 | **跨模块补账 #2**(厂家 BR-MFR-06 落地) |
| `803120410` | 同设备下型号中文名已存在 | uk_equipment_name 兜底 / 应用层预校验 |
| `803120411` | 默认厂家不在关联集合内 | IN-EQ-04 / IN-MOD-11 校验 |
| `803120412` | 至少保留一个关联厂家 | IN-MOD-12 / BR-MOD-09 校验 |
| `803120413` | 型号规格字段非法 | name/nameEn/mark 空/超长 |
