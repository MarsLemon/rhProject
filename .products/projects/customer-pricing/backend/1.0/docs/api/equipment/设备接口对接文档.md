## 2. 码表与公共字段说明

### 2.1 status 业务状态

| 码 | 含义 | 表现 |
|----|------|------|
| 1 | 启用 | 出现在 `by-category` 和 `nav-tree`(前提:父分类也启用) |
| 0 | 停用 | 从 `by-category` 不可见,`nav-tree` 该节点隐藏;后台 `/list` 仍可见(前端置灰);可重新启用 |

### 2.2 设备编码 code(只读,系统生成)

- 格式:`父分类 code + "." + 3 位序号`(如 `6.001`、`6.001.005.001`);
- 新增后立即返回,**前端不可手填、不可编辑**;
- 删除后序号不复用(取现存最大 +1,防外部引用漂移)。

### 2.3 名称约束

- 中文名必填 1~100 字,**同分类下精确唯一**(对齐 manufacturer 中文名唯一);
- 英文名选填 ≤200 字,不查重;中英文名共同参与列表关键词过滤(不区分大小写)。

### 2.5 /list groupBy 字段

| 取值 | 返回结构 |
|------|---------|
| `category`(或 `Category`) | `EquipmentTreeNodeVo[]`,每项含 `id/code/name/equipments`(扁平按分类聚合,嵌套树由前端组) |
| 空 / 其他 | `EquipmentVo[]` 扁平数组,按 code 升序 |

## 3. 后台接口明细

### 3.1 新增设备

```
POST /web/equipment/add
```

**请求体**:

```json
{
  "categoryId": 10,
  "name": "主机柴油机",
  "nameEn": "Main Diesel Engine"
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| categoryId | parent `true` | 所属分类 id;校验存在、未删除、未停用 |
| name | parent `true` | 中文名,1~100 字,同分类下精确唯一 |
| nameEn | 否 | 英文名,≤200 字 |

**响应 data**:

```json
{
  "id": 1,
  "code": "6.001"
}
```

---

### 3.2 重命名设备

```
PUT /web/equipment/rename
```

**请求体**:

```json
{
  "id": 1,
  "name": "新主机柴油机",
  "nameEn": "New Main Diesel Engine"
}
```

**响应 data**:`null`(成功时返回 200)

---

### 3.3 启用/停用

```
PUT /web/equipment/change-status
```

**请求体**:

```json
{
  "id": 1,
  "status": 0
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| id | parent `true` | 设备 id |
| status | parent `true` | 1 启用 / 0 停用,仅允许 0/1 |

**响应 data**:`null`

---

### 3.4 删除设备

```
GET /web/equipment/delete/{id}
```

**路径参数**:

| 参数 | 说明 |
|------|------|
| id | 设备 id;本期仅校验存在+逻辑删除 |

**响应 data**:`null`

---

### 3.5 设备列表(关键词+分类过滤)

```
GET /web/equipment/list?keyword={keyword}&categoryId={categoryId}&groupBy={groupBy}
```

**查询参数**:

| 参数 | 必填 | 说明 |
|------|------|------|
| keyword | 否 | 匹配 code/name/nameEn(不区分大小写),为空时返回全量 |
| categoryId | 否 | 父分类 id 过滤;为空时不过滤分类 |
| groupBy | 否 | `category` 返回嵌套聚合树;空/其他值返回扁平数组 |

**响应 data(groupBy=空 / 扁平)**:

```json
[
  {
    "id": 1,
    "categoryId": 10,
    "code": "6.001",
    "name": "主机柴油机",
    "nameEn": "Main Diesel Engine",
    "status": 1,
    "updateTime": "2026/09/21 10:30:00",
    "updateBy": "张三"
  }
]
```

**响应 data(groupBy=category / 嵌套聚合)**:

```json
[
  {
    "id": 10,
    "code": "6",
    "name": "机械设备主要部件",
    "nameEn": null,
    "parentId": null,
    "level": 1,
    "children": [],
    "equipments": [
      {
        "id": 1,
        "categoryId": 10,
        "code": "6.001",
        "name": "主机柴油机",

        "status": 1,
```

## 4. 前台接口明细(无细粒度权限点,登录态即可)

### 4.1 按分类查询启用设备(型号维护下拉 + 询价页设备下拉)

```
GET /web/portal/equipment/by-category/{categoryId}
```

**响应 data**:`PortalEquipmentByCategoryVo[]`(按 code 升序)

```json
[
  {
    "id": 1,
    "code": "6.001",
    "name": "主机柴油机",
    "nameEn": "Main Diesel Engine",
    "categoryId": 10
  }
]
```

> 父分类不存在/已删除时返回 `[]`;父分类已停用时也返回 `[]`(IN-EQ-09 / BR-EQ-09 前台可见性约定,设备分类"父停用 → 子孙前台隐藏"语义一致)。

---

### 4.2 前台导航树(询价嵌入页 FR-01 步骤①)

```
GET /web/portal/equipment/nav-tree
```

**v1.3 修订**:nav-tree 仅返启用状态设备叶子按 categoryId 分组,**不含分类树本身**。分类树由设备分类模块 `/web/portal/equipment-category/nav-tree` 独立承担(该接口已交付并被前端消费),前端双源聚合。

**响应 data**:`PortalEquipmentNavTreeVo[]`(按 categoryId 分组的设备叶子数组;停用分类/停用设备不展示;按分类 code 升序)

```json
[
  {
    "id": 10,
    "code": "6.001",
    "name": "推进用柴油机",
    "nameEn": null,
    "equipments": [
      {
        "id": 1,
        "code": "6.001.001",
        "name": "主机柴油机",
        "nameEn": "Main Diesel Engine",
        "categoryId": 10
      }
    ]
  }
]
```

> 父分类停用 / 已删除 / 不存在时,该分类下的设备叶子不展示(IN-EQ-09 前台可见性语义传播)。

## 5. 错误码表(8031203xx)

| code | 含义 | 触发场景 |
|------|------|---------|
| `803120301` | 设备编码已存在 | uk_code 兜底 / 应用层预校验 |
| `803120302` | 父分类不存在或已删除 | addEquipment 时 getCategoryById 返回 null |
| `803120303` | 父分类已停用 | addEquipment 时父分类 status=0 |
| `803120304` | 设备状态取值非法 | status 非 0/1 |
| `803120305` | 设备不存在或已删除 | rename/changeStatus/delete 时 id 不存在 |
| `803120306` | 同分类下设备中文名已存在 | uk_category_name 兜底 / 应用层预校验 |

## 6. 跨模块补账(主人已拍板)

- 设备分类 ← 设备:**挂载设备不可删 / 设备叶子不可加子级**(BR-EQ-06)。设备模块交付后,在设备分类模块补一行查询即可,不在设备模块动作。
- 设备 ← 型号:**被型号关联不可删**(BR-EQ-05)。型号模块交付后,在设备模块加一行校验。
