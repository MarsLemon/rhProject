## 3. 当前核心口径（校对基线，引用时以此为准）

1. **计价唯一路径（D15；v1.14 去件数系数，D18）**：单价 = Σ(职级费率 × 人数) × 单件标准工时；**行金额 = 单价 × 数量**（多件作业不再折减）；无独立价格表、无"手填单价"入口；
2. **标准工时回溯两级（v1.7 / v2.2 / v2.6 起）**：型号级（一条配置可多选型号）> 设备级；机型组（model_group）已退役；
3. **最终报价 = Max(合计保底价, 明细合计) × 影响系数**（D16/D17）——项保底价 = 该项人员配置综合费率 × 最低计费工时（默认 8h，**按一份计**：不乘数量）；合计保底价 = Σ(各已勾选服务项的项保底价)；影响系数 = Max(紧急, 地点, 时间)（各未命中 = 1.0，**只作用于最终报价**）；原"预算合计 = 明细合计 + 基础服务费"（D13）已作废；
4. **套餐 = 组合包**（D9/D11：可整体取消、明细可取消勾选/调数量，**无份数**、无折扣、无一口价；套餐小计 = Σ(勾选明细行金额)）；
5. **服务项分组非必填**（D2：未分组为合法状态，前台归入"其他"）；
6. **服务信息与影响系数（D17）**：订单级必填三项——**是否紧急**（不紧急/紧急）、**服务地点**（大地区 > 国家 > 地点，**必填到国家、地点选填**）、**服务时间**（具体日期 → 距询价天数 ≥ 0）；系数可配在 紧急程度字典 / 服务地点（**任意一级，解析 地点级 > 国家级 > 大地区级，留空=任意兜底**）/ 距询价天数区间，**取最大值（Q-9 已决）**（各未命中 = 1.0）；**已按原型实现闭环并经端到端验证（2026-09-11）**：前台采集 + 后台「影响系数」页维护 + 预览模拟器；Q-9 合成方式 = 取最大值（已决）、Q-10 保底"按一份"、Q-11 大地区可设系数（区域兜底）；**Q-12 时间系数 <1.0 档是否削减保底、Q-13 紧急与服务时间是否重复计费——已于 2026-09-18 随 Q-9（取最大值）一并消解**（K ≥ 1.0 保底不被削减；紧急/临近排期不再叠加，见业务梳理 §11.1 与需求文档 §10）；
7. **已退役清单**（不要实现）：series 层级、`service_item_tier_price`、`service_item_price` 与 `price_mode`、`model_group` / `model_group_member`、**`base_service_fee` 与"基础服务费（固定加收）"口径（D13 → D16）**、**件数工时系数（R-34 / `labor_qty_coefficient` / `inquiry_snapshot.qty_coefficient`，D18：多件按全额计，不得再乘任何件数系数）**、R-13 / R-15 / R-18 / **R-34**、IN-MC-02/03/04/07/08/**11**/**14a**、IN-EQ-05、IN-DEL-04。
