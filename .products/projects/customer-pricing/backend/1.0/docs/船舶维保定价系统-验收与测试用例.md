## R-01 设备分类树仅用于导航

**TC-R01-P**：首页目录树展开 "主机柴油机 Main diesel engine"，点击节点展开型号但不产生任何价格项；点击设备名后进入询价流程。
**TC-R01-N**：点击目录树的非叶节点（分类名），页面不进入询价步骤、不产出价格（导航节点不参与定价）。

## R-02 型号平铺展示（无系列层级）

**TC-R02-P**：设备选择主机柴油机（Main diesel engine）后，型号下拉平铺列出 35 个型号，无 "MAN B&W系列 / WinGD系列 / J-ENG UEC系列" 等分组标签。
**TC-R02-N**：型号下拉出现任何系列分组（`optgroup`）或系列前缀，视为不通过。

## R-03 型号-厂家多对多

**TC-R03-P**：选择 6S60MC-C，厂家列表 = MC_MANUFACTURERS 全部 9 家（HD HYUNDAI、Hanwha(Doosan/HSD)、HME(STX)、HHM、CSSC、MITSUI、Kawasaki、Hitachi Zosen、Makita；不含 Sulzer——Sulzer 为 WinGD 系列授权厂）。
**TC-R03-N**：选择 6UEC45LSE-Eco-B2 时厂家列表出现 MC_MANUFACTURERS 厂家（应仅含 UEC_MANUFACTURERS 的 J-ENG / CSSC / Akasaka）。

## R-04 选型号后厂家联动并默认选中

**TC-R04-P**：选择型号 6S60MC-C 后，厂家下拉自动选中第一家（默认厂家），列表项与型号厂家集合一致。
**TC-R04-N**：选择型号后厂家下拉为空，或选中项不在该型号厂家集合内。

## R-05 缸数为型号属性（自动带出、只读）

**TC-R05-P**：选择 5S60MC-C，缸数输入框自动显示 "5"，且处于只读状态（不可编辑、加减按钮无效）。
**TC-R05-N**：选择型号后缸数未自动带出，或输入框可手动修改（只读失效）。

## R-06 切换设备/型号清空下游

**TC-R06-P**：完成 型号→厂家→维保类型→勾选建议项 后，切换设备为辅助柴油发电机组（Aux. diesel generator aggregates, complete），型号/厂家/维保类型/套餐/建议项/自定义输入全部清空；**但订单级的服务信息（是否紧急/服务地点/服务时间）保留不清空**（v2.4，D17），切换后预算按新设备标准工时重算、服务信息与系数照旧参与最终报价。
**TC-R06-N**：切换设备后仍残留上一设备的型号或已选建议项。

## R-07 维保类型按设备挂载，默认第一个（D10：5年/10年是周期，不是类型）

**TC-R07-P**：主机柴油机（Main diesel engine）下维保类型下拉默认选中第一项，列表仅含该设备挂载的类型；**不含"5年保养""10年保养"**（它们是"液压和电控系统保养"的保养周期选项，见 TC-R28）。
**TC-R07-N**：维保类型下拉默认空，或包含其他设备才有的维保类型，或出现"5年保养/10年保养"作为类型。

## R-08 适用范围内套餐默认自动选中

**TC-R08-P**：型号/厂家/维保类型就绪后，"标准保养套餐"自动选中，预算卡片出现套餐行。
**TC-R08-N**：前置条件满足后套餐仍未被选中（预算无套餐行）。

## R-09 套餐（组合包）可整体取消；明细数量可调（D9；份数已取消，v2.3）

**TC-R09-P**：① 套餐默认勾选；点击取消入口后套餐整体取消、其明细全部退出预算合计；重新勾选后明细按默认恢复。② 套餐明细数量 1→3，该行金额 ×3，合计实时更新。③ 套餐区域**不出现任何份数控件**，套餐小计 = Σ(勾选明细行金额)（无整包倍数因子）。
**TC-R09-N**：取消套餐后其明细金额仍计入合计，或明细数量无法调整；或页面仍提供"套餐份数"调节入口（旧口径残留）。

## R-10 套餐内明细可取消勾选（D9，修订原 D4）

**TC-R10-P**：展开套餐明细，取消勾选任一项后该项退出套餐明细合计（其余项不变）；预算页同步显示剩余明细；取消勾选与调整数量（≥1）均允许。
**TC-R10-N**：套餐明细无取消入口（锁定），或取消后金额仍计入。

## R-11 建议项分组展示与搜索

**TC-R11-P**：自由选择区按项目分组（HCU、Electric control system、Tacho system 等）展示；整组勾选生效；搜索 "FIVA" 仅过滤出 FIVA valve overhaul 相关项（on board / workshop 两条）；**未分组服务项归入兜底分组"其他"展示，不丢项**。
**TC-R11-N**：搜索关键字不匹配的项目仍显示，整组勾选只勾中部分项，或未分组服务项被隐藏/丢失。

## R-12 建议项数量可调、可取消

**TC-R12-P**：建议项数量 1→3 后行金额×3；取消勾选后该行从预算消失。
**TC-R12-N**：建议项数量无法调整，或取消勾选后行金额仍计入合计。

## R-17 组合包无折扣（D11）

**TC-R17-P**：套餐小计 = Σ(勾选明细行金额)——无折扣率、无一口价、无份数；取消任一明细/调整数量后，小计按剩余明细实时重算且**不存在任何折算系数**。

## R-40 服务时间与距询价天数（D17；v2.4 新增）

**TC-R40-P**：① 服务日期为必填日期选择器，**最小值 = 当天**（过去日期不可选、手填被拒，IN-INQ-05）；② 当天提交 → lead_days = 0，命中 [0,2] 档（初始 1.2500）；③ 服务日期 = 提交日 +5 天 → lead_days = 5，命中 [3,7] 档（1.1000）；④ 服务日期 = 提交日 +20 天 → lead_days = 20，命中 [8,29] 档（1.0000）；⑤ 服务日期 = 提交日 +45 天 → 命中 [30,∞) 档（0.9500）；⑥ 时间系数区间四段且首段从 0 开始、末段 max_days = NULL → 保存成功；⑦ 后端收到负 lead_days（异常数据）→ 按 0 处理（最紧急档），不报错、不产生负系数。
**TC-R40-N**：① 服务日期早于当天仍可提交；② lead_days 计算含时分秒导致跨天偏移（应按自然日差）；③ 时间系数区间存在空洞（如 [0,7] 与 [10,30]，8–9 天无档）仍保存成功（应被 IN-MC-18 拒绝）；④ 区间交叠仍保存成功。

## R-41 影响系数（取三者最大值，只作用于最终报价，D17；v2.4 新增，Q-9 已决 2026-09-18）

**TC-R41-P**：① 影响系数 = Max(紧急系数, 地点系数, 时间系数)（如 Max(1.2000, 1.1500, 1.1000) = 1.2000，保留 4 位）；② 三维均未配置/未命中 → 影响系数 = 1.0000，最终报价 = 计价基数；③ **系数只作用于订单级最终报价**——明细行金额、套餐小计、明细合计、合计保底价**均不含系数**（逐行核对）；④ 仅改服务信息（如 不紧急→紧急）→ 明细合计与合计保底价不变，只有最终报价变化；⑤ 三类系数与合成系数随快照冻结（inquiry.urgency_coef/location_coef/lead_time_coef/coefficient），调系数规则后历史单不变；⑥ 后台客户定价单详情展示三类系数与合成值。
**TC-R41-N**：① 系数被计入明细行金额或套餐小计（破坏"每行可解释"与审计链）；② 某维度未命中时被当作 0 计算（应视为 1.0）；③ 系数为 0 或负数仍能保存（应被 IN-MC-17 拒绝）；④ 快照未冻结系数，调规则后历史单最终报价变化。

**~~TC-IN-04~~（~~IN-DEL-04 机型组删除前置~~）—— v2.0 作废**：机型组退役，model_group 表不再存在，本用例随 IN-DEL-04 一并作废（保留编号供对照）。

- P：编辑展示规则/地点影响系数/服务项，保持原维度不变保存 → 保存成功（不把自身旧值判为重复）。
- N：编辑保存被"已存在"拦截（未排除自身行）。

**TC-IN-06（IN-EDT-02 关闭周期前置）**
- P：对已启用周期且名下有带周期 规则/工时 的类型关闭 cycle_flag → 编辑弹窗实时预警并在保存时拒绝，列出清理清单。

**TC-IN-07（IN-EDT-03 型号变更所属设备）**
- P：型号从设备 A 改属设备 B → 名下型号级 labor_standard 的冗余 equipment_id 同步重算；同步后违反 IN-MC-10 则拒绝保存。
- N：冗余字段仍指向设备 A（IN-MC-10 校验失效，回溯错乱）。

**TC-IN-08（IN-STP-01 停用语义）**
- P：停用被引用的维保类型/分类节点 → 前台立即隐藏；名下配置保留不命中；已提交询价单金额不变；重新启用后恢复。
- N：停用导致历史询价单金额变化，或名下配置被连带删除。

**TC-IN-09（IN-NAM-01 更名与编码不可变）**
- P：修改维保类型/服务项名称 → 各引用处实时显示新名（按 id 解析），历史询价单仍显示快照旧名；后台编辑界面无 code 修改入口。
- N：改名后引用处仍显示旧名，或历史单回查目录显示新名（违反快照原则）。

**TC-IN-10（IN-MC-18 时间系数区间完整性，v2.4 新增）**
- P：保存时间系数区间 [0,2] / [3,7] / [8,29] / [30,∞)（末段 max_days = NULL）→ 通过（区间不重叠且连续覆盖 [0,∞)）。
- N：① 区间存在空洞（[0,2] 与 [5,30]，3–4 天无档）仍保存成功；② 区间交叠（[0,10] 与 [8,20]）仍保存成功；③ 不存在 max_days IS NULL 的行（无法覆盖远期）仍保存成功——三者均应**拒绝保存**并提示缺口/重叠位置。

**TC-IN-11（IN-MC-17 影响系数取值合法，v2.4 新增）**
- P：紧急/地点/时间系数填 1.15、1.2、0.95 → 保存成功；填 3.5（越出建议区间 [0.5,3.0]）→ 保存成功但给出**告警**。
- N：填 0 或 -1 → **拒绝保存**（不得入库，避免把价格清零或反向）。

**TC-IN-12（IN-MC-19 服务地点树层级与系数挂载，v2.4 新增）**
- P：大地区（无上级）→ 国家（挂大地区）→ 地点（挂国家）逐级新增成功；把系数挂到**大地区、国家或地点任一级** → 保存成功（大地区级即区域兜底行）。
- N：① 地点直接挂在某大地区下（跳过国家，出现"三级树"变两级或四级）仍保存成功；② 同一优先级下重复配置（如同一大地区配两条区域兜底行）仍保存成功（应拒绝/提示）；③ 同一父节点下新增同名子节点仍保存成功（应拒绝）。

## 后台客户定价单查看（TC-INQ，v2.2 新增，对应 需求文档 v1.6 FR-09）

> 前台提交的询价单（inquiry）在后台的承载与查看；「客户定价单」为询价单的后台展示名。
> Demo 入口：`prototype-design/admin/inquiry.html`（读取共享存储 `pc_mgmt_inquiries_v1` + 内存演示种子）。

**TC-INQ-01（列表：筛选 + 分页 + 排序）**
- P：进入后台「询价受理 · 客户定价单」→ 列表默认按提交时间倒序；关键词（单号/客户/船名/型号/厂家）输入即过滤、有「重置」按钮；条数 >10 时出现分页器（页码/上下页/每页条数），筛选变更回到第 1 页。
- N：关键词命不中任何字段仍显示全量，或筛选后停在越界页码、无重置入口。

**TC-INQ-02（详情：冻结快照完整性）**
- P：点「查看」→ 抽屉展示客户与设备上下文（型号/厂家为自定义文本时按快照文本显示并标注）、**服务信息（是否紧急 / 服务地点 / 服务日期 / 距询价天数，v2.4）**、明细行（套餐/可选项分组、单价/数量/行金额；**v2.7 起无件数系数列**）、推导要素（回溯级别 · 职级×人数 · 费率合计 × 标准工时；未冻结时省略）、**价格构成（明细合计 → 合计保底价（触发时展示保底补足额）→ 影响系数（三类与合成）→ 最终报价，带币种，v2.4）**、补充说明。
- N：明细行金额与前台提交时预算不一致，或合计缺保底价/影响系数/最终报价、缺行金额；仍显示已退役的"基础服务费"行（旧口径残留）。

**TC-INQ-03（端到端：前台提交 → 后台可见）**
- P：前台（PC/H5 demo）完成选择并提交 → 后台「客户定价单」页刷新后新单置顶，单号（IQ+日期+序号）唯一递增，明细金额与前台提交时预算完全一致；后台已开着询价页时，提交后自动出现新单提示。
- N：提交后后台看不到新单、单号重复，或金额与前台预算不一致（快照冻结失败）。

**TC-INQ-04（只读：IN-INQ-03 / IN-INQ-02）**
- P：列表与详情均无编辑/删除入口；调整目录配置（费率/工时/影响系数规则/最低计费工时）后重新打开历史单，快照金额与系数不变。
- N：出现任何修改入口，或改配置后历史单金额跟随变化（回查目录重算，违反快照原则）。

**TC-INQ-05（服务信息与新价格构成展示，v2.4 新增）**
- P：① 列表可见**最终报价**（原"预算合计"）；② 详情展示服务信息三项与距询价天数；③ 价格构成按「明细合计 → 合计保底价 →（触发时）保底补足额 → 影响系数（取 Max(三类) 合成）→ 最终报价」逐行展示，且**最终报价 = Max(保底价, 明细合计) × 系数**可用页面数字手工复算一致；④ 明细行的行金额之和 = 明细合计（系数未混入明细行）。
- N：① 详情缺服务信息或影响系数；② 页面数字无法复算出最终报价（口径不一致）；③ 明细行金额含系数导致行金额之和 ≠ 明细合计。
