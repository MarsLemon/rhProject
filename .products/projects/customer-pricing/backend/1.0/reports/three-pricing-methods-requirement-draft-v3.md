## 1. 现状与基础

### 1.1 固定部分(不可配)

```
单条明细金额 = Σ(职级费率 × 人数) × 单件标准工时 × 数量
标准价 = Max(合计保底价, 明细合计)
最终报价 = 定价公式(标准价)   // 定价公式内容见 §5 各方案
```

### 1.2 因子划分

| 类别         | 包含                                  | 作用       |
| ------------ | ------------------------------------- | ---------- |
| **基础因子** | 职级费率 / 标准工时 / 数量 / 计件基准 | 推标准价   |
| **影响因子** | (可配的分类)                          | 调节最终价 |

### 1.3 业务事实

- **客户档案已存在**(船东/船管公司、联系人、历史记录)
- **默认一船一单**(业务方确认)
- **客户侧只看最终价**(D17)

## 2. 成本大表分析

### 2.1 6 种计价逻辑概览

成本大表是公司销售内部定价的成熟体系,**支持 6 种定价法 + 多级审批**。

| #   | 方法           | 业务语义             |
| --- | -------------- | -------------------- |
| 1   | 成本加成       | 成本 + 计划毛利率    |
| 2   | 市场导向       | 看竞品行情 + 毛利率  |
| 3   | 边际成本(船套) | 大批量同型船分摊成本 |
| 4   | 效用           | 按客户使用价值       |
| 5   | 自定义         | 名称 + 金额(兜底)    |
| 6   | 其他费用/佣金  | 名称 + 金额(附加项)  |

### 2.2 客户定价场景对照

| #   | 成本大表方法   | 客户定价适用性 | 判定                            |
| --- | -------------- | -------------- | ------------------------------- |
| 1   | 成本加成       | ❌ 不适用      | D17 已定客户侧不暴露成本        |
| 2   | 市场导向       | ❌ 不适用      | 客户定价是参考报价,不是竞品对比 |
| 3   | 边际成本(船套) | ❌ 不适用      | 客户询价是单船单次,无"船套"概念 |
| 4   | 效用           | ❌ 不适用      | 维保是劳务型,非按用量计费商品   |
| 5   | 自定义         | ✅ 已沿用      | 客户定价已有"自定义"附加项      |
| 6   | 其他费用/佣金  | ✅ 已沿用      | 客户定价已有"代理佣金"附加项    |

### 2.3 4 种不适用方法的详细分析

#### #1 成本加成 — 不适用

- **成本大表用法**:成本 + 计划毛利率
- **客户定价场景**:客户侧不看成本构成(D17)
- **结论**:加成无意义,客户报价是劳务汇总,不暴露成本

#### #2 市场导向 — 不适用

- **成本大表用法**:看竞品行情定价
- **客户定价场景**:是 B2C 询价参考,不是 B2B 竞品对比
- **结论**:无竞品对比场景,无市场参考机制

#### #3 边际成本(船套) — 不适用

- **成本大表用法**:大批量同型船分摊成本
- **客户定价场景**:默认一船一单(§1.3),无"船套"概念
- **结论**:批量场景业务边界模糊,场景不匹配

#### #4 效用 — 不适用

- **成本大表用法**:按客户使用价值定价
- **客户定价场景**:维保是劳务型服务,非"按用量计费"商品
- **结论**:无"使用价值"概念,无法套用

### 2.4 2 种可沿用方法

| 方法              | 沿用方式                          |
| ----------------- | --------------------------------- |
| 自定义(#5)        | 客户定价已有"自定义"附加项,沿用   |
| 其他费用/佣金(#6) | 客户定价已有"代理佣金"附加项,沿用 |

## 3. 成本大表深层逻辑借鉴

虽然 6 种方法不直接适用,但其**底层设计思想**值得深挖借鉴。

### 3.1 4 个可借鉴的底层逻辑

| 借鉴点                         | 业务本质                  | 是否借鉴             | 备注                   |
| ------------------------------ | ------------------------- | -------------------- | ---------------------- |
| **Strategy Pattern(策略模式)** | 加新方法不动现有数据      | ✅**P0 已定**        | 调研报告 §5.1          |
| **多对多关联**                 | 询价单↔客户/系数 N:N 关联 | ✅ 浅借鉴            | 审计可追溯             |
| **快照冻结 + 生效期**          | 历史询价不受调价影响      | ✅**已实现**         | R-23                   |
| **跨币种 + 汇率快照**          | 国外客户询价锁定          | ✅**基础能力(必做)** | 调研报告 §5.2,见借鉴 D |

### 3.2 借鉴方式详解

#### 借鉴 A:Strategy Pattern(策略模式)

**业务本质**:把"定价方法"从写死公式升级为可切换方法,加新方法不动老方法。

**未来支持的定价方法**(详见 §5):标准定价 + 紧急加价 + VIP + 远程诊断 + 包干价,可扩展。

#### 借鉴 B:多对多关联(部分借鉴)

**业务本质**:所有定价相关实体走 N:N 关联表,审计可追溯。

```
询价单 (inquiry)
├─ N:N 客户档案 (inquiry_customer)
├─ N:N 影响因子快照 (inquiry_factor)
├─ 1:N 服务项 (inquiry_item)
└─ 1:N 定价公式快照 (inquiry_formula)
```

#### 借鉴 C:快照冻结 + 生效期(已借鉴)

- 询价单提交冻结(R-23)
- 职级费率卡带生效期
- 调费率/调公式不影响历史询价单

#### 借鉴 D:跨币种 + 汇率快照(必做基础能力,非定价方案)

- 询价单加币种 + 汇率字段
- 提交时按当时汇率锁定
- 销售邮件双币种展示
- **不属于 §5 定价方案范畴,作为基础能力一并实现**

### 3.3 决策点(1 项)

| #   | 决策           | 推荐                        |
| --- | -------------- | --------------------------- |
| C1  | 多对多关联深度 | **浅(只关联客户+影响因子)** |

## 4. 可配置定价策略架构(业务视角详细方案)

### 4.1 业务目标

**业务方**可自主配置定价公式,无需开发频繁发版介入:

- 加新定价方案(紧急加价/VIP/远程诊断/包干价/未来扩展)→ 业务方配置即可
- 改公式影响旧询价单 → **不影响**(快照冻结)
- 业务方能试算/调试 → 所见即所得

### 4.2 业务方操作流程

```
业务方日常工作流:
① 进入"定价策略配置"页
② 看到已有影响因子(紧急/地点/时间...)
③ 配置步骤(可配置表头/类型/字典)
④ 写定价公式(拖拽 + 纯文本辅助)
⑤ 在线试算(输入标准价 + 各影响项系数 → 看结果)
⑥ 保存 → 生成 formula_version
```

### 4.3 核心业务规则

| #     | 规则                     | 业务含义                                  |
| ----- | ------------------------ | ----------------------------------------- |
| R-A1  | 影响因子 = 分类,可添加   | 业务方/系统/外部接口可新增影响因子        |
| R-A2  | 影响项 = 配置行,1:N      | 每个影响因子下挂任意多行                  |
| R-A3  | 系数 = 必有,数值         | 公式中 × 引用                             |
| R-A4  | 备注 = 文本              | 公式中不可引用                            |
| R-A5  | 影响项可配字段           | 表头/类型/字典/接口取值                   |
| R-A6  | 公式 = 数学表达式        | 含变量(影响因子.系数)+ 函数(Max/Min/...)  |
| R-A7  | 公式必含标准价           | 或勾选"无标准价"(远程诊断等例外)          |
| R-A8  | 公式版本管理             | 每次保存递增 version,询价单快照记 version |
| R-A9  | 公式调试/试算            | 输入测试值实时看输出                      |
| R-A10 | 改公式不影响历史询价单   | 快照已冻结                                |
| R-A11 | 基础数学函数             | Max/Min/Round/If/Abs/Ceil/Floor(7 个)     |
| R-A12 | 公式编辑 = 拖拽 + 纯文本 | 拖拽构建器主导,纯文本辅助                 |
| R-A13 | 富文本渲染(可选)         | MathLive 预览数学公式                     |

## 5. 定价方案(按推荐优先级，可参考，实际方案编辑由业务编写公式)

### 5.1 优先级排序总览

**所有定价方案共同遵守的公式**(不可变):

```
单条明细金额 = Σ(职级费率 × 人数) × 单件标准工时 × 数量
标准价 = Max(合计保底价, 明细合计)
最终报价 = 定价公式(标准价)   // 定价公式内容是每个方案唯一不同的地方,见下方
```

| 优先级   | 方案                    | 推荐理由                   | 详细方案 |
| -------- | ----------------------- | -------------------------- | -------- |
| **基础** | 标准定价方案            | 客户定价默认,已实现        | 见 §5.2  |
| **P0**   | 紧急加价方案            | 现有雏形,改造小,业务价值大 | 见 §5.3  |
| **P1**   | VIP 客户价方案          | 客户档案已就位,锁单关键    | 见 §5.4  |
| **P1**   | 远程诊断定价方案        | 覆盖长尾小客户,无标准价    | 见 §5.5  |
| **P1**   | 询价包干价方案          | 区间报价 + 销售落定        | 见 §5.6  |
| P2       | 续约折扣 / SLA          | 需订单域/服务承诺前置      | 后置     |
| —        | 季节性折扣 / 保底价拆分 | 不推荐                     | 见 §5.7  |

### 5.2 标准定价方案(基础方案,已实现)

#### 1. 一句话

**客户定价的默认定价法 — 工时推导单价 × 数量。**

#### 2. 公式

```
定价公式:标准价 * Max(地点, 时间)
```

#### 3. 决策点

| #   | 决策         | 现状                  |
| --- | ------------ | --------------------- |
| S1  | 单价推导路径 | **统一工时标准**(D15) |
| S2  | 影响系数     | **Max(地点, 时间)**   |

#### 4. 融合方式(基础方案无需新融合)

- 与基础因子:**自身就是基础因子的核心实现**
- 与影响因子:正交(紧急/地点/时间 影响因子作用于标准价)
- 与报价公式:`最终报价 = 定价公式(标准价)`,标准价是公式输入
- 与影响因子分类:无新增(只承载基础数据)

#### 5. 详细业务方案

##### 业务方操作流程

1. 后台维护职级字典 + 费率卡(带生效期)
2. 后台维护标准工时(型号级多选 > 设备级两级回溯)
3. 客户询价时按型号 + 维保类型匹配
4. 系统按公式算标准价

##### 核心业务规则

| 规则 | 含义                             |
| ---- | -------------------------------- |
| R-S1 | 职级费率卡带生效期,调薪全局生效  |
| R-S2 | 标准工时两级回溯(型号 > 设备)    |
| R-S3 | 多件作业按全额计(件数系数已退役) |

##### 业务验收标准

- V-S1:职级费率卡生效期生效
- V-S2:标准工时两级回溯生效
- V-S3:多件全额计
- V-S4:保底价生效(<明细时托底)

##### 业务方使用场景

**场景:客户询价标准保养**

1. 客户选型号 6S35ME + 维保类型 + 周期
2. 系统匹配标准工时 → 算行金额
3. 套餐合计 + 保底价 → 取高者 = 标准价

### 5.3 P0 紧急加价方案 ⭐

#### 1. 一句话(含推荐理由)

**客户要得急,加价;要得不急,原价。从乘数升级为独立定价法 — 业务可解释,成本可测算,数据可沉淀。**

#### 2. 公式

```
定价公式:标准价 + 标准价 × (加价率 - 1)
```

#### 3. 决策点(6 项)

| #   | 决策               | 推荐                               |
| --- | ------------------ | ---------------------------------- |
| U1  | 加价率配置方       | **运营配**                         |
| U2  | 字典档位           | **5 档(含特急/灾难)**              |
| U3  | 与影响因子关系     | **完全解耦(独立定价法)**           |
| U4  | 加价金额可见性     | **销售邮件可见**                   |
| U5  | 加价说明路径       | **邮件 + 后台双通道**              |
| U6  | 公式中是否合成加价 | **直接引用加价金额,不再 Max 合成** |

#### 4. 加价率与融合方式

**加价率建议**:

| 紧急程度 | 加价率     | 备注        |
| -------- | ---------- | ----------- |
| 不紧急   | 100%       | 默认        |
| 紧急     | 120%(+20%) | 加班成本    |
| 非常紧急 | 150%(+50%) | 外协 + 加班 |
| 特急     | 协议价     | 单谈        |
| 灾难级   | 协议价     | 单谈        |

**升级理由矩阵**:

| #   | 理由           | 升级后效果                                 |
| --- | -------------- | ------------------------------------------ |
| 1   | 业务可见       | 销售邮件明示加价金额                       |
| 2   | 成本可测算     | 加价率=真实成本(加班/外协/违约/物流)       |
| 3   | 与影响因子解耦 | 独立定价法,不再走 Max 合成                 |
| 4   | 多档扩展       | 2 档 → 5 档                                |
| 5   | 数据沉淀       | 加价金额独立字段,统计"加价贡献率"          |
| 6   | 业务可拍板     | 加价率=绝对加价幅度,易决策                 |
| 7   | 可解释         | 销售说清"加价 $20 万 = 加班 + 外协 + 物流" |
| 8   | 维度清晰       | 与地点/时间正交,不再互相挤压               |

**融合方式**:

- 与基础因子:正交(基础因子推标准价,加价因子推加价额)
- 与影响因子:**完全解耦**,独立定价法,不再走 Max 合成
- 与报价公式:`最终报价 = 标准价 + 加价金额`,加价行独立展示
- 与询价单:新增 `urgency_level_id` + `urgency_premium_amount` + `urgency_premium_rate` + `urgency_premium_explanation` 字段,均进快照
- 与影响因子分类:**影响因子 = "紧急加价"**,影响项 = 5 档加价率

#### 5. 详细业务方案

##### 业务方操作流程

1. 运营配置紧急程度字典(5 档)
2. 运营配置各档加价率
3. 运营配置加价说明模板
4. 客户询价选紧急程度 → 系统算加价金额
5. 销售邮件显示"紧急加价 $X(理由)"

##### 核心业务规则

| 规则 | 含义                               |
| ---- | ---------------------------------- |
| R-E1 | 5 档(不急/紧急/非常紧急/特急/灾难) |
| R-E2 | 加价率独立配置,运营维护            |
| R-E3 | 加价金额 = 标准价 × (加价率 - 1)   |
| R-E4 | 销售邮件必显示加价理由             |
| R-E5 | 加价金额进询价单快照               |
| R-E6 | 不与影响因子 Max 合成              |

##### 业务验收标准

- V-E1:5 档字典可配
- V-E2:加价率可独立维护
- V-E3:销售邮件含加价金额 + 理由
- V-E4:快照冻结加价金额
- V-E5:不影响历史询价单

##### 业务方使用场景

**场景:客户紧急询价**

1. 客户选"紧急"
2. 系统:加价 = 100 万 × 20% = 20 万
3. 销售邮件:"标准价 100 万 + 紧急加价 20 万 = 120 万"
4. 销售解释:"加价 20% = 加班 + 物流"

### 5.4 P1 VIP 客户价方案 ⭐

#### 1. 一句话(含推荐理由)

**同产品,不同客户不同价。按客户等级折扣 — 锁单关键手段,客户档案已就位可直接做。**

#### 2. 公式

```
定价公式:标准价 × VIP 折扣率
```

#### 3. 决策点(5 项)

| #   | 决策             | 推荐                     |
| --- | ---------------- | ------------------------ |
| V1  | 等级体系         | **5 级(含战略)**         |
| V2  | 评定方           | **系统自动 + 运营复核**  |
| V3  | 复评周期         | **一年**                 |
| V4  | 战略客户是否参与 | **不参与(协议价)**       |
| V5  | 等级快照口径     | **询价时点**(同影响因子) |

#### 4. 等级体系与融合方式

**等级体系**:

| 等级 | 折扣率 | 评定标准                         | 备注           |
| ---- | ------ | -------------------------------- | -------------- |
| 普通 | 100%   | 默认                             | 无等级走标准价 |
| 银卡 | 95%    | 年度询价 ≥ 3 次 或 累计 ≥ 50 万  | 自动           |
| 金卡 | 90%    | 年度询价 ≥ 5 次 或 累计 ≥ 200 万 | 自动           |
| 钻石 | 85%    | 战略合作                         | 运营手工       |
| 战略 | 协议价 | 不参与折扣                       | 协议价单谈     |

**融合方式**:

- 与基础因子:正交(基础因子推标准价,VIP 折扣按客户等级作用于标准价)
- 与影响因子:正交(紧急/地点/时间仍走 Max,VIP 折扣作用于基础价)
- 与报价公式:`VIP 报价 = 标准价 × VIP 折扣率`,折扣独立展示
- 与询价单:新增 `customer_id` + `customer_level` + `vip_discount_rate` 字段,均进快照
- 与客户档案:**客户档案已存在**,只需新增等级字段
- 与一船一单:N:N 关系
- 与影响因子分类:**影响因子 = "VIP 等级"**,影响项 = 5 级折扣率

#### 5. 详细业务方案

##### 业务方操作流程

1. 运营配置等级体系(5 级)
2. 系统按规则自动评定等级
3. 运营复核
4. 客户询价按等级折扣
5. 一年后自动复评

##### 核心业务规则

| 规则 | 含义                           |
| ---- | ------------------------------ |
| R-V1 | 5 级(普通/银卡/金卡/钻石/战略) |
| R-V2 | 自动评定 + 运营复核            |
| R-V3 | 一年复评一次                   |
| R-V4 | 战略客户协议价,不参与折扣      |
| R-V5 | 等级快照冻结在询价时点         |

##### 业务验收标准

- V-V1:5 级可配
- V-V2:自动评定按规则
- V-V3:运营可手工调整
- V-V4:战略客户协议价
- V-V5:等级快照生效

##### 业务方使用场景

**场景:金卡客户询价**

1. 客户档案已标"金卡"
2. 询价时识别 → 应用 90% 折扣
3. 销售邮件:"标准价 100 万 × 90% = 90 万(金卡价)"

### 5.5 P1 远程诊断定价方案 ⭐(无标准价)

#### 1. 一句话(含推荐理由)

**视频/电话指导,不出场 — 覆盖长尾小客户,纯人力低成本,边际成本接近零。**

#### 2. 公式

```
定价公式:远程费率 × 时长   // 勾选"无标准价"
```

#### 3. 决策点(2 项)

| #   | 决策            | 推荐                      |
| --- | --------------- | ------------------------- |
| B1  | 是否做远程诊断  | **做(P1)**                |
| —   | 远程费率如何配? | **运营配 + 时长上限封顶** |

#### 4. 远程费率与融合方式

**远程费率建议**:

| 咨询类型 | 费率(假设) | 备注     |
| -------- | ---------- | -------- |
| 视频诊断 | $80/h      | 主力场景 |
| 电话咨询 | $50/h      | 轻量场景 |
| 邮件书面 | $30/封     | 异步场景 |

**时长封顶**:单次询价 ≤ 4 小时,超出转现场服务。

**融合方式**:

- 与基础因子:**替代**(远程诊断不走"职级费率 × 标准工时")
- 与影响因子:正交(地点系数可能仍适用;时间系数不适用)
- 与报价公式:`远程诊断报价 = 远程费率 × 时长`,独立定价
- **与标准价:勾选"无标准价"**,系统不校验标准价存在(§4 公式编辑器支持)
- 与询价单:新增 `pricing_method = remote_diagnosis` + `remote_hours` + `remote_rate` 字段
- 与客户侧:D17 持续(只看最终价)
- 与销售邮件:明示"远程诊断费 $X(视频诊断 Y 小时)"
- 与业务边界:沉淀远程案例库

#### 5. 详细业务方案

##### 业务方操作流程

1. 运营配置远程费率(视频/电话/邮件)
2. 客户选远程诊断 + 填预估时长
3. 系统按"远程费率 × 时长"算报价
4. 时长封顶(默认 4h,超出转现场)

##### 核心业务规则

| 规则 | 含义                  |
| ---- | --------------------- |
| R-R1 | 3 类(视频/电话/邮件)  |
| R-R2 | 远程费率独立配        |
| R-R3 | 时长上限封顶(默认 4h) |
| R-R4 | 公式勾"无标准价"      |
| R-R5 | 沉淀远程案例库        |

##### 业务验收标准

- V-R1:3 类费率可配
- V-R2:时长封顶生效
- V-R3:公式无标准价校验
- V-R4:超 4h 提示转现场服务

##### 业务方使用场景

**场景:小客户远程咨询**

1. 客户选"远程诊断"+"视频 2 小时"
2. 系统:80 × 2 = 160 USD
3. 销售邮件:"远程诊断费 160 USD(视频 2 小时)"

### 5.6 P1 询价包干价方案(区间报价) ⭐

#### 1. 一句话(含推荐理由)

**系统给"8-12 万"区间报价,期内有效 — 客户决策快,销售沟通轮次减半。**

#### 2. 公式

```
定价公式:标准价 × 落定系数(销售在 [0.95, 1.10] 区间内选)
```

#### 3. 决策点(2 项)

| #   | 决策             | 推荐                               |
| --- | ---------------- | ---------------------------------- |
| B2  | 是否做询价包干价 | **做(P1)**                         |
| —   | 区间宽度如何配?  | **下限 95% / 上限 110%(建议起点)** |

#### 4. 区间配置与融合方式

**区间配置建议**:

| 标准价档位 | 区间宽度     | 备注            |
| ---------- | ------------ | --------------- |
| < 10 万    | [95%, 110%]  | 小单,窄区间     |
| 10-50 万   | [95%, 115%]  | 中单,中等区间   |
| 50-100 万  | [95%, 120%]  | 大单,宽区间     |
| > 100 万   | [协议, 协议] | 超大单,不走区间 |

**融合方式**:

- 与基础因子:正交
- 与影响因子:正交
- 与报价公式:`最终报价 = 标准价 × 落定系数`
- 与询价单:新增 `pricing_method = package_price` + `price_range_min` + `price_range_max` + `final_locked_price` 字段
- 与销售流程:**新增**销售落价环节
- 与客户侧:客户看到区间,销售邮件落定具体值
- 与有效期:期内有效(如 7 天),逾期重算
- 与影响因子分类:**影响因子 = "包干价落定系数"**,影响项 = 各档位的可选落定系数

#### 5. 详细业务方案

##### 业务方操作流程

1. 运营配置区间宽度(按标准价档位)
2. 系统生成区间(如 9.5-11 万)
3. 客户拿区间报价
4. 销售在区间内落定具体值
5. 7 天内有效,逾期重算

##### 核心业务规则

| 规则 | 含义                   |
| ---- | ---------------------- |
| R-P1 | 区间按标准价档位配     |
| R-P2 | 销售落定价 ∈ 区间      |
| R-P3 | 7 天有效,逾期重算      |
| R-P4 | >100 万走协议,不走区间 |
| R-P5 | 销售落定价进快照       |

##### 业务验收标准

- V-P1:区间按档位自动生成
- V-P2:销售落定校验在区间内
- V-P3:逾期重算提示
- V-P4:超大单走协议流程

##### 业务方使用场景

**场景:中型客户询价**

1. 系统:标准价 10 万 → 区间 [9.5 万, 11 万]
2. 客户拿区间:"9.5-11 万"
3. 销售落定:"10.5 万"
4. 销售邮件:"标准价 10 万 × 落定系数 1.05 = 10.5 万"

## 附录:术语表

| 术语                       | 解释                                                        |
| -------------------------- | ----------------------------------------------------------- |
| Strategy Pattern(策略模式) | 加新定价方法不动现有公式,像插卡一样往"方法架"上挂           |
| 定价公式                   | 业务方配置的数学表达式,作用于标准价得最终报价               |
| 标准价                     | Max(合计保底价, 明细合计),不可变                            |
| 影响因子                   | 定价公式中的变量分类(可添加),如紧急/地点/时间/VIP等级       |
| 影响项                     | 影响因子下的具体配置行(可配置),含系数 + 数据类型 + 备注     |
| 系数                       | 影响项的核心数值字段,公式中 × 引用                          |
| 数据类型                   | 影响项必填字段,决定取值来源如何配(文本/数字/日期/下拉/接口) |
| 备注                       | 影响项的固定文本字段,公式中不可引用                         |
| 紧急加价方案               | 客户要求加急,在标准价基础上加收(独立定价法)                 |
| 加价率                     | 紧急程度的百分比,如 120%(+20%)                              |
| 加价的钱花在哪             | 加班费 + 外协费 + 违约成本 + 物流加急                       |
| VIP 客户价方案             | 按客户等级给予不同折扣                                      |
| 客户等级                   | 普通/银卡/金卡/钻石/战略 5 级                               |
| 客户档案                   | 客户主数据(已存在):等级、联系信息、历史记录                 |
| 一船一单                   | 默认业务模型:一艘船对应一个询价单                           |
| 远程诊断定价方案           | 视频/电话指导,不出场(无标准价)                              |
| 询价包干价方案             | 系统给"8-12 万"区间报价,销售落定具体值                      |
| 续约折扣                   | 一次性签 N 年维保,年单价递减                                |
| 基础因子                   | 职级费率/标准工时/数量,推标准价                             |
| 无标准价勾选               | 公式编辑器顶部选项,勾选后不校验标准价存在                   |
