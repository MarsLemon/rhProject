# Lesson 0005:16 项怎么加成总成本(跨币种)

<div class="meta">主题:总成本汇总 | 难度:★★☆ | 阅读时间:6 分钟</div>

---

## 一句话

**16 项成本各自算完小计,先按汇率折算成项目主币种,再全部相加,得到一个数 — 总成本。**

---

## 汇总分 3 步

```
16 项成本各自的小计
       ↓ 步骤 1:按汇率折算
全部用项目主币种(通常是人民币)表达
       ↓ 步骤 2:相加
总成本(一个数)
       ↓ 步骤 3:快照
总成本锁定,后续成本变动不影响历史汇总
```

---

## 为什么需要跨币种

公司接的生意可能来自全球客户:

```
国内客户 → 报价用人民币
美国客户 → 报价用美元
欧洲客户 → 报价用欧元
中东客户 → 报价用迪纳尔
```

而公司采购材料、付工资**也有不同币种**:

```
美国服务器 → 用美元采购
中国工程师 → 用人民币发工资
欧洲设备   → 用欧元买
```

所以**汇总前必须先换算**到主币种。

---

## 怎么换算:汇率快照

**关键规则**:**在某个时点把汇率"拍死",后续不再变**。

```
汇率快照 = "项目 X 在 2026-09-15 那天:
    1 美元 = 7.10 人民币
    1 欧元 = 7.85 人民币
    1 迪纳尔 = 1.94 人民币"
```

> **什么时候锁**:**销售开始定价那一刻**(状态从 "等待定价" 切到 "定价编辑中")。

---

## 为什么要在"开始定价"时锁

| 情境 | 影响 |
|---|---|
| **不锁汇率** | 总成本每天随汇率波动,销售和客户都说不清"这单到底多少钱" |
| **锁了汇率** | 销售报价有依据,客户看到的是**确定的价格** |

> **关键洞察**:**汇率锁定的本质是"让报价有依据、可追溯"** — 不是为了汇率精准。

---

## 算例:加总成总成本

某项目含以下成本:

| 成本项 | 币种 | 金额 |
|---|---|---|
| 售前费用 | 人民币 | 50,000 |
| 生产材料 | 美元 | 10,000 |
| 软件开发人工 | 人民币 | 200,000 |
| 仓储物流 | 欧元 | 5,000 |

**步骤 1:换算**(假设汇率 1 USD = 7.10 CNY,1 EUR = 7.85 CNY)

| 成本项 | 原币 | 主币(CNY) |
|---|---|---|
| 售前费用 | CNY 50,000 | 50,000 |
| 生产材料 | USD 10,000 | 71,000 |
| 软件开发人工 | CNY 200,000 | 200,000 |
| 仓储物流 | EUR 5,000 | 39,250 |

**步骤 2:相加**

```
总成本 = 50,000 + 71,000 + 200,000 + 39,250 = 360,250 CNY
```

**步骤 3:快照锁定**

```
项目 X · 总成本快照 · 2026-09-15
汇率快照:1 USD = 7.10 CNY,1 EUR = 7.85 CNY
总成本:360,250 CNY

→ 后续即便汇率变了,这单的总成本依然是 360,250 CNY
```

---

## 谁负责汇总

```
16 项各自填完(各填各的)
       ↓
销售部销售触发"汇总"操作
       ↓
系统自动:
   1. 取汇率快照(从基础数据)
   2. 16 项按汇率折算
   3. 求和
   4. 锁定
       ↓
产出"总成本"一个数
```

> **关键**:**汇总是销售触发的**,不是各填完自动汇总。销售决定"我准备开始定价了",才汇总。

---

## 汇率快照的"双向"含义

汇率快照同时锁定两件事:

1. **成本端的汇率** — 算总成本用
2. **售价端的汇率** — 4 级审批的"售价区间"系数也用同一份快照

> **为什么**:**保证"成本+售价"用同一套汇率**,否则会出现"成本按今天的汇率算,售价按明天的汇率算"的混乱。

---

## 关键认知

| # | 要点 |
|---|---|
| 1 | 总成本 = 16 项折算后的求和 |
| 2 | **必须先换算**,因为不同项可能不同币种 |
| 3 | 汇率在"开始定价"时**快照锁定** |
| 4 | 锁定后,后续成本变动不影响已汇总的总成本 |
| 5 | 汇率同时锁定成本端 + 售价端(用同一份) |

## 自测题

<div class="quiz">

**Q1. 为什么要在"开始定价"那一刻锁汇率?**

- A. 因为那时候最准
- B. 为了让后续报价有依据、可追溯
- C. 法律规定
- D. 系统自动锁,人没法选

<details>
<summary>显示答案</summary>
<div class="quiz-answer">
<strong>B</strong> — 锁定汇率的本质是<strong>让报价有依据、可追溯</strong>。锁定后,无论汇率怎么变,这单的报价不会反复改。
</div>
</details>

</div>

<div class="quiz">

**Q2. 一项成本是 1000 美元,当时汇率 1 USD = 7 CNY。汇总时折算成多少人民币?**

- A. 1000
- B. 7000
- C. 1007
- D. 视当天汇率而定

<details>
<summary>显示答案</summary>
<div class="quiz-answer">
<strong>B</strong> — 1000 USD × 7 = 7000 CNY。注意:用的是<strong>快照汇率</strong>(当时的 7),不是当天汇率。
</div>
</details>

</div>

<div class="quiz">

**Q3. 16 项都填完了,系统会自动汇总成总成本吗?**

- A. 是,自动
- B. 否,要销售触发"开始定价"操作
- C. 取决于系统设置
- D. 要等所有上级审批

<details>
<summary>显示答案</summary>
<div class="quiz-answer">
<strong>B</strong> — 汇总是销售<strong>主动触发</strong>的,触发点 = 销售开始定价的那一刻。在那之前,即便 16 项都填完,也不会汇总。
</div>
</details>

</div>
