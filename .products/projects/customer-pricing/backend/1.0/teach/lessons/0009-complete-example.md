# Lesson 0009:一个完整例子(把所有东西串起来)

<div class="meta">主题:综合应用 | 难度:★★★ | 阅读时间:8 分钟</div>

---

## 一句话

**用一个真实的"船舶配件订单"把 5 阶段 + 3 部门 + 16 成本 + 总成本 + 6 定价法 + 4 级审批 + 9 状态全部串起来。**

---

## 场景

某客户要订**一批船舶主机配件**(船套单位),金额较大,涉及跨币种(美元支付),需要 4 级审批。

**项目基本信息**:

- 项目:船舶主机配件订单
- 客户:美国船东
- 币种:USD
- 数量:10 船套(批量)
- 预计交付:港口现场安装

---

## 完整流程

### Step 1:销售发起项目(launched)

**谁**:国内销售部 销售1

**干了啥**:

- 录入项目基本信息(客户、币种、需求)
- 项目进入 **launched** 状态

---

### Step 2:3 部门并行填成本(waiting-cost)

**项目进入 waiting-cost**,3 个部门同时开始填:

#### 销售部填 3 项

| #   | 成本项       | 金额(原币) | 主币(CNY) |
| --- | ------------ | ---------- | --------- |
| ①   | 项目售前费用 | USD 5,000  | 35,500    |
| ②   | 代理费       | CNY 30,000 | 30,000    |
| ③   | 履约成本     | CNY 20,000 | 20,000    |

#### 采购部填 2 项

| #   | 成本项   | 金额(原币) | 主币(CNY) |
| --- | -------- | ---------- | --------- |
| ④   | 施工材料 | USD 50,000 | 355,000   |
| ⑤   | 仓储物流 | EUR 8,000  | 62,800    |

#### 生产部填 9 项

| #   | 成本项         | 金额(原币)  | 主币(CNY) |
| --- | -------------- | ----------- | --------- |
| ⑥   | 项目售前人工   | CNY 80,000  | 80,000    |
| ⑦   | 规划直接人工   | CNY 100,000 | 100,000   |
| ⑧   | 直接采购材料   | CNY 500,000 | 500,000   |
| ⑨   | 生产/集成人工  | CNY 300,000 | 300,000   |
| ⑩   | 软件开发人工   | CNY 200,000 | 200,000   |
| ⑫   | 认证费         | USD 20,000  | 142,000   |
| ⑪   | 其他生产费用   | CNY 50,000  | 50,000    |
| ⑬   | 施工人工       | CNY 150,000 | 150,000   |
| ⑭   | 特殊环境附加费 | CNY 30,000  | 30,000    |
| ⑮   | 运维成本       | CNY 100,000 | 100,000   |
| ⑯   | 售后成本       | CNY 80,000  | 80,000    |

---

### Step 3:销售汇总成总成本(costing)

**项目进入 costing**,销售触发"汇总":

```
汇率快照(2026-09-15 锁定):
   1 USD = 7.10 CNY
   1 EUR = 7.85 CNY

总成本 = 各项求和
       = (35,500 + 30,000 + 20,000)         ← 销售 3 项
       + (355,000 + 62,800)                  ← 采购 2 项
       + (80,000 + 100,000 + 500,000 + 300,000 + 200,000
          + 142,000 + 50,000 + 150,000 + 30,000 + 100,000 + 80,000) ← 生产 9 项
       = 2,235,300 CNY
```

**项目进入 cost-complete**

---

### Step 4:销售选定价法 + 出报价(pricing)

**项目进入 waiting-price → pricing**,销售开始定价:

**关键决策**:这是**大批量设备**,用**边际成本**(船套单位)!

**销售填的 4 个字段**:

- 计划销售规模:**10 船套**
- 单船套成本:**223,530 CNY**(总成本 / 10)
- 投资回报周期:**3 年**
- 单船套定价:**290,000 CNY**

**算法**(系统自动算):

```
单船套成本 = 2,235,300 / 10 = 223,530 CNY
期望回报率 = 20%
单船套定价 = 223,530 × (1 + 0.2 × 3) = 357,648 CNY
但销售填了 290,000(初步定价)
```

**修正定价**(销售与客户谈判后):

```
修正后单船套定价 = 280,000 CNY
修正毛利率 = (280,000 - 223,530) / 280,000 ≈ 20%
```

**附加项**:

- 自定义:特殊包装 5,000 CNY

**报价结构**:

```
主报价:边际成本(10 船套 × 280,000) = 2,800,000 CNY
附加项:特殊包装 = 5,000 CNY
──────────────────────────
项目总报价 = 2,805,000 CNY
```

---

### Step 5:4 级审批(set-price-submit → set-price-complete)

**项目进入 set-price-submit**,4 级依次填:

| 级别            | 售价区间(基础数据系数)           | 实际售价      |
| --------------- | -------------------------------- | ------------- |
| 销售人员(销售1) | 95%~105% = 2,664,750 ~ 2,945,250 | **2,805,000** |
| 销售部长        | 90%~110% = 2,524,500 ~ 3,085,500 | **2,750,000** |
| 销售副总        | 85%~115% = 2,384,250 ~ 3,225,750 | **2,720,000** |
| 总裁            | 80%~120% = 2,244,000 ~ 3,366,000 | **2,700,000** |

**每级的预估毛利率**(系统自动算):

| 级别     | 实际售价  | 毛利率                                         |
| -------- | --------- | ---------------------------------------------- |
| 销售人员 | 2,805,000 | (2,805,000 - 2,235,300) / 2,805,000 ≈**20.3%** |
| 销售部长 | 2,750,000 | ≈**18.7%**                                     |
| 销售副总 | 2,720,000 | ≈**17.8%**                                     |
| 总裁     | 2,700,000 | ≈**17.2%**                                     |

---

### Step 6:项目完成(complete)

**项目最终总报价 = 总裁的 2,700,000 CNY**(≈ USD 380,282)

**项目进入 complete 状态**,归档,不能再改。

---

## 完整状态时间线

```
销售1 发起 ─→ launched
              ↓
       waiting-cost    (1-2 天,3 部门并行填)
              ↓
       costing          (几分钟,销售汇总)
              ↓
       cost-complete
              ↓
       waiting-price
              ↓
       pricing           (1-3 天,销售编辑报价)
              ↓
       set-price-submit
              ↓
       set-price-complete (3-7 天,4 级审批)
              ↓
       complete          ✓ 项目完成
```

## 这个例子里学到的

| #   | 知识点            | 在例子里怎么体现                               |
| --- | ----------------- | ---------------------------------------------- |
| 1   | 5 阶段            | 需求对接 → 规划 → 生产 → 交付 → 售后           |
| 2   | 3 部门            | 销售3项+采购2项+生产9项=14(矩阵去采购售后空白) |
| 3   | 16 项成本         | 矩阵每个"有活干"的格子都有                     |
| 4   | 跨币种 + 汇率快照 | USD/EUR → CNY,锁定 7.10/7.85                   |
| 5   | 6 种定价法        | 用了**边际成本**(船套场景)                     |
| 6   | 4 级审批          | 销售1 → 部长 → 副总 → 总裁,各填各的实际售价    |
| 7   | 9 状态流转        | 严格顺序,卡点明确                              |
| 8   | 报价 ↔ 成本多对多 | 主报价关联到生产批次                           |

## 关键认知(总览)

| #   | 要点                                                                |
| --- | ------------------------------------------------------------------- |
| 1   | 成本大表 = 5 阶段 + 3 部门 + 16 成本 + 6 定价法 + 4 级审批 + 9 状态 |
| 2   | 每一步都有**明确的责任人**和**操作规则**                            |
| 3   | **快照**是核心(汇率快照、报价快照、4级区间快照)                     |
| 4   | **审计追溯**贯穿全程(谁定的、什么时候定的、改过几次)                |
| 5   | 状态机保证**流程不乱**,不让任何人跳过或越权                         |
