# 6 种定价法速查表

## 4 种主方法

| 方法 | 销售要填什么 | 适用场景 |
|---|---|---|
| **成本加成** | 计划毛利率 | 简单项目,成本清楚,客户是熟客 |
| **市场导向** | 计划毛利率 + 市场参考价 | 竞品多,客户会货比三家 |
| **边际成本** | 船套数 + 单船套成本 + 回本年限 + 单船套定价 | 大批量设备(船套/批次) |
| **效用** | 效用类型 + 建议方式 | SaaS、订阅、按用量 |

## 2 种附加项

| 方法 | 销售要填什么 | 适用场景 |
|---|---|---|
| **自定义** | 名称 + 金额 | 上面 4 种都不合适 |
| **其他费用** | 名称 + 金额 | 代理费、特殊开支 |

## 决策树

```
大批量?
├─ 是 → 边际成本
└─ 否 ↓
       价值感明确?
       ├─ 是 → 效用
       └─ 否 ↓ 有市场参考价
              ├─ 是 → 市场导向
              └─ 否 → 成本加成

兜底 → 自定义
挂账 → 其他费用
```

## 一份报价结构

```
主报价(4 选 1)+ 附加项(2 选 N,可叠加)
   ↓
项目总报价 = 所有报价项之和
```
