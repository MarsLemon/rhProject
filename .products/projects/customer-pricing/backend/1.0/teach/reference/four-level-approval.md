# 4 级审批速查表

## 4 级顺序

```
销售人员 → 销售部长 → 销售副总 → 总裁
   ①         ②          ③          ④
```

## 售价区间(默认)

| 级别 | 默认系数 | 权限 |
|---|---|---|
| 销售人员 | 95% ~ 105% | 最窄,只能微调 |
| 销售部长 | 90% ~ 110% | 较宽,部门让步 |
| 销售副总 | 85% ~ 115% | 更宽,跨部门平衡 |
| 总裁 | 80% ~ 120% | 最宽,终审决策 |

## 每级 3 件套

| 字段 | 来源 |
|---|---|
| 售价区间 | 系统算 = 项目总报价 × 区间系数 |
| 实际售价 | 本级填 |
| 预估毛利率 | 系统自动算 = 1 - 实际售价 / 总成本 |

## 关键规则

- **项目最终总报价 = 总裁的实际售价**
- 每级只能在自己的区间内定价
- 总裁可"打回",但留 audit trail
