# 业务术语统一口径

| 术语 | 解释 |
|---|---|
| **成本大表** | 公司内部"做一笔生意要花多少钱、卖多少钱"的完整记录与定价系统 |
| **5 阶段** | 需求对接 / 规划与设计 / 生产 / 交付与实施 / 售后维护 |
| **3 部门** | 销售部 / 采购部 / 生产部 |
| **16 项成本** | 5 × 3 矩阵中"有活干"的格子数 |
| **总成本** | 16 项按汇率折算后的求和 |
| **汇率快照** | 在"开始定价"时锁定的汇率,后续不再变 |
| **6 种定价法** | 4 主方法(成本加成/市场导向/边际成本/效用)+ 2 附加项(自定义/其他费用) |
| **主报价** | 一份报价中用 1 种主方法算的报价 |
| **附加项** | 挂在主报价上的额外费用 |
| **修正定价** | 销售谈判后改的实际价格 |
| **修正毛利率** | 系统自动算 = 1 - 总成本 / 修正定价 |
| **4 级审批** | 销售人员 → 部长 → 副总 → 总裁 |
| **售价区间** | 每级只能在系统给的范围内定价 |
| **区间系数** | 从基础数据配置,锁定后不变 |
| **9 状态** | 项目从发起到完成的 9 个状态节点 |
| **状态机** | 状态严格按顺序流转,不能跳 |
| **打回** | 总裁可让项目回到前一状态,留 audit |
| **审计追溯** | 任何报价都有据可查(谁定的、什么时候、改过几次) |
| **船套** | 船舶/工业大批量设备的批量单位(1 船套 = 一套设备的批量) |
| **项目最终总报价** | 总裁填的实际售价 |
| **基础数据** | 汇率、售价区间系数等全局配置,在项目开始定价时快照 |
| **报价 ↔ 成本多对多** | 一份报价可关联多个成本项 |
