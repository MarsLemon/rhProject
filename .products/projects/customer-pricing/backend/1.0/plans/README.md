## 4. 建议开发顺序（依赖链）

```
已完成：①厂家 ✅、②设备分类 ✅ ─┐
                                  ├→ ③设备 → ④型号（多对多+默认厂家）
                                  │      └→ 设备-维保类型挂载 ← ⑥维保类型 + 保养周期字典
                                  └→ ⑦项目分组 → ⑧服务项 → ⑨职级/费率卡/件数系数
                                             → ⑩标准工时（两级回溯 + 构成行 + 分档）→ ⑪套餐/明细
                                             → ⑫展示规则 → 定价引擎（工时推导）
                                             → ⑬服务信息与影响系数（M3：pricing_param + 地点/紧急/时间系数）
                                             → 提交/快照/邮件/咨询单（M2）
                                             → 型号级多选精细化（M4）→ Excel 导入 + 巡检（M5）
```

> 顺序依据 FR-07 维护链与 §12 里程碑：M1 目录与工时定价是全部后续能力的基础。
