| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 现象     | 设备分类 plan §6.2 已定义 `/web/portal/equipment-category/nav-tree`(只返分类节点);设备 plan §6.2 又定义 `/web/portal/equipment/nav-tree`(返"分类+设备叶子完整树") |
| 风险     | 两份 plan 互不知情;前端组装点未定;联调返工;两接口并存时前端聚合逻辑分裂                                                                                           |

| 默认口径 | 待主人拍板二选一                                                                                                                                                  |
| 选项 A   | 设备 nav-tree 出"完整树",设备分类 nav-tree 退役(设备 plan §6.3 + 设备分类 plan §6.3 已暗示,但未拍)                                                                |

| 建议     | 选 A。设备分类 nav-tree 仅返分类部分价值低;前端少接 1 个接口;完整树天然支持合并                                                                                   |
