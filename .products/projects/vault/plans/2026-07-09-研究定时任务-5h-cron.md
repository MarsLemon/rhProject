# 研究定时任务 — 5h 周期自动调研

## 背景

主人要个**自动调研定时任务**:每 5 小时跑一轮,跨平台并行采集(GitHub / 小红书 / B 站 / 掘金 / 其他提升技术的站点),落 Thinkpad → 摘要 → 归档,封顶 20 条/轮(软上限)。

**目标**:

1. 主人手不动,定期自动往 Thinkpad 喂新料
2. 落到三个目录(10-raw → 20-concepts → 22-entities),frontmatter 带可追溯字段
3. 封顶 20 条/轮,**软上限**(可超,主人手调) — 2026-07-09 主人调整口径

## 设计要点

### 流水线(单轮)

```
[schtasks 5h 触发]
     ↓
[node scripts/research-cron/run-research-batch.mjs]
     ↓
[1. agent-reach 多平台并行:github / xhs / bilibili / juejin / ...]
     ↓
[2. 原始材料 → 落 Thinkpad/10-raw-原始材料/articles/<YYYY-MM-DD>/<platform>-<slug>.md]
     ↓
[3. AI 摘要 → 落 Thinkpad/20-concepts-已消化笔记/调研/<YYYY-MM-DD>-<slug>.md]
     ↓
[4. 归档(如能抽象) → 落 Thinkpad/22-entities-实体档案/<slug>.md]
     ↓
[5. 写 99-log/2026-07/log-<date>.md 一行;计数器进每条 frontmatter]
     ↓
[6. 满 20 条(软)→ 写 logs/research-cron/<batch-id>.log,继续;不强制停]
```

### frontmatter 字段(必填)

| 字段              | 类型   | 说明                | 例                                                         |
| ----------------- | ------ | ------------------- | ---------------------------------------------------------- |
| `cron-batch`      | string | 批号 `YYYYMMDD-HH`  | `20260709-00`                                              |
| `cron-counter`    | int    | 本轮序号 1-N        | `3`                                                        |
| `source-platform` | enum   | 平台                | `github` / `xiaohongshu` / `bilibili` / `juejin` / `other` |
| `source-url`      | url    | 原文直链            | `https://...`                                              |
| `sources`         | list   | 指向 10-raw 文件    | `[10-raw-原始材料/articles/2026-07-09/github-foo.md]`      |
| `confidence`      | enum   | high / medium / low | `medium`                                                   |

> SCHEMA.md 既有字段(`title` / `created` / `updated` / `type` / `tags` / `agent` / `owner`)保留,新增上面 4 个 cron-\* 字段。

### 调度

- **触发器**:Windows Task Scheduler(`schtasks /Create`)
- **频次**:每 5 小时一次,起点 00:00 → 触发时间 `00:00` / `05:00` / `10:00` / `15:00` / `20:00`
- **执行命令**:`node E:\rhProject\scripts\research-cron\run-research-batch.mjs`
- **执行账户**:主人当前登录账户(用 `/RU <username>` + `/RL HIGHEST`,但不强制 — 主人 2026-07-09 拍板"你是 admin,直接 /Create")

### 采集 SDK

- **复用 `~/.claude/skills/agent-reach/`**(主人 2026-07-09 拍板)
- 子进程调用 `agent-reach doctor --json` 拿平台可用性 + `agent-reach search "<query>"` 拿结果
- 不新装 npm 依赖,零新代码入侵

### 计数与暂停

- **计数器位置**:每条 frontmatter `cron-counter`,**不单独存 state.json**(2026-07-09 主人拍)
- **20 条软上限**:超 20 不停,继续落 + log 写"超 20,继续",主人手调是否清理
- **批号 / 时戳**:每轮自取系统时间 → `YYYYMMDD-HH`

## 验证

### 自动化

1. **手动跑一次**:`node scripts/research-cron/run-research-batch.mjs --dry-run`
   - 期望:不落盘、只打日志,显示将采的平台 + 计划落点
2. **真跑一次**:`node scripts/research-cron/run-research-batch.mjs`
   - 期望:≥1 平台采到 ≥1 条 → 落 10-raw + 20-concepts → 写 log
3. **注册 schtasks**:`schtasks /Create /TN "Research-Cron-5h" /TR "node E:\rhProject\scripts\research-cron\run-research-batch.mjs" /SC HOURLY /MO 5 /ST 00:00 /RU <user> /F`
   - 期望:`schtasks /Query /TN "Research-Cron-5h"` 显示存在
4. **等 5h 看自动跑**:次轮 05:00 后查 `logs/research-cron/` + `Thinkpad/10-raw-原始材料/articles/2026-07-09/` 有新文件

### 手动

1. 主人开 Obsidian 看 Thinkpad,确认新文件 frontmatter 字段齐 + sources 链对
2. 主人跑 `schtasks /Query /FO LIST /V` 看 Research-Cron-5h 任务详情
3. 主人手改 `cron-counter` 验证计数逻辑(可选)

- 不调 Claude / Copilot API 消化摘要(摘要 = AI 跑,但 agent-reach 已含 AI 摘要输出)
