## 2. 后端核心实现

### 2.1 `ReActOrchestrator`(基于 demo 移植)

```java
public String chat(String appKey, ChatStreamReq req, SseEmitter emitter) {
    var messages = buildMessages(req);              // system + history + user
    var tools = toolRegistry.resolve(req.getTools()); // 动态按开关
    int maxIter = 10, maxSearch = 5, iter = 0, searchCnt = 0;
    
    while (iter++ < maxIter) {
        var stream = provider.stream(messages, tools, isLastNoTool(searchCnt, maxSearch));
        var (content, toolCalls) = consumeStream(stream, emitter);
        
        if (toolCalls.isEmpty()) {
            // 最终回答,触发验证(本期不做 A2/A3,只触发一次)
            emitDone(emitter, content);
            return content;
        }
        
        // 工具调用:执行 + 拼回 messages
        for (var tc : toolCalls) {
            var result = toolRegistry.execute(tc);
            messages.add(toolResultMessage(tc, result));
            searchCnt += isSearchTool(tc) ? 1 : 0;
        }
    }
}
```

### 2.2 `KnowledgeBaseTool`

- 入参:`{ query: string }`
- 实现:`BailianKnowledgeBaseAdapter.search(query)` 调 `BailianService.knowledgeBaseSearch`
- 出参:`{ results: [{title, url, snippet, type='kb'}] }`

### 2.3 `WebSearchTool`

- 入参:`{ query: string }`
- 实现:`TavilyWebSearchAdapter.search(query)` 调 `https://api.tavily.com/search`
- 出参:`{ results: [{title, url, content, type='web'}] }`

### 2.4 `<<<suggest>>>` 后端剥离

`ReActOrchestrator` 流式消费时实时检测:
```java
String cleanContent = stripSuggestionsLive(content);
emitter.send(SseChunk.chunk(cleanContent));
// 同时把 suggestions 作为独立 event 发出
if (suggestions != null) emitter.send(SseChunk.suggest(suggestions));
```

→ 前端不再需要这个逻辑,移除 `stripSuggestionsLive` / `extractSuggestions`(三端)。

## 5. 反问点(等 Qoder 拍板)

1. KB 检索后端是否缓存相同 query?**推荐 LRU 100 条,TTL 5min**(百炼按量计费)
2. ReAct 循环前端是否要透传 thought 流?**推荐后端 emit `thought` event,前端可隐藏**——M1 已设计
3. WebSearch 失败是否降级到纯 KB?**推荐降级,且 `tool_result` 带 `degraded: true` 标记**
4. 出题 appKey 的 prompt 是否复用答疑 prompt?**推荐不复用**,出题有独立 system prompt(走 `bizParams` 注入)
