## 角色与使用场景

| 角色 | 使用场景 | 系统入口 |
|---|---|---|
| 客户(船东/船管) | 自助询价 | 客户定价系统(嵌入页) |
| 销售(国内/国外/备件) | 客户跟进 + 内部定价 | 销售团队工作台 |
| 采购 | 询价后采购材料 | 采购模块 |
| 生产工程师 | 维保方案执行 | 工程师工作台 |
| AI 网关调用方 | AI 模型调用 | AI 网关 API |
| 培训学员 | 学习任务 | 培训中心 |

---

## 完整流程(主公视角)

### 1. 客户询价 → 内部定价 → 项目交付

```
① 客户(船东)在嵌入页自助询价
   → 系统按客户定价规则实时算预算
   → 生成询价单邮件推送给销售
② 销售跟进,内部按成本大表定价
   → 4 级审批(销售→部长→副总→总裁)
   → 出最终报价给客户
③ 项目启动,采购部 + 生产部填 16 项成本
   → 系统汇总成总成本
   → 跨币种汇率快照锁定
④ 维保方案执行(采购材料 + 工程师施工)
⑤ 售后维护(运维成本 + 售后成本)
```

### 2. AI 网关调用

```
① 调用方 → AI 网关 API
② 网关路由(OpenAI / DashScope)
③ 限流 + 计费
④ 返回结果 + 监控埋点
```

### 3. 培训学习

```
① 管理员分配学习任务
② 学员完成课程
③ 系统记录进度
④ 主管查看报表
```
