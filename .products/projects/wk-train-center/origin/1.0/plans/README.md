# 项目计划目录

> 本目录用于存放 `wk-train-center` 项目的后续计划文件。

## 存放规则

- 新计划统一放在本目录，不再散落到 `tasks/`、项目根目录或代码仓根目录。
- 文件名采用：`YYYY-MM-DD-{主题}.md`。
- 仅服务某一版本的计划，放入 `plans/{version}/`；跨版本计划留在 `plans/` 根目录。
- Mobile 版本目录使用 `mobile1.x/`，不使用 `mobile-1.x/`、`mobile-v1.x/` 或 `v1.x/`。
- 创建计划前先确认目标子仓当前 Git 分支，或读取对应 `docs/version-registry.json`。
- 移动、重命名计划文件前，先检查并更新项目内引用；发现断链时同步维护 `../LINK-BREAKAGE.md`。

## 文档归档边界

- 项目计划：本目录。
- 项目设计、验证、评审、问答等：`.products/` 下对应项目目录或 `.products/specs/`。
- 经验、踩坑、教训、可复用方法论：`Thinkpad/22-entities-实体档案/agent-经验库/`。
- 调研材料：`Thinkpad/20-concepts-已消化笔记/调研/`。
- 主人原话与决策记录：`Thinkpad/99-log/`。

## 写作要求

- 开头写明目标、范围、版本和关联仓。
- 按可执行步骤拆分，并给出每步验证方式。
- 明确风险、依赖、回滚方式和完成标准。
- 引用其他文档时使用相对路径，并在文件迁移后检查链接。
