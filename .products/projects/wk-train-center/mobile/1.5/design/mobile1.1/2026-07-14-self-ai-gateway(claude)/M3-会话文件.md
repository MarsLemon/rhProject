## 2. 后端核心实现

### 2.1 文件签名统一

新增 `POST /api/ai/files/sign`:
```java
@PostMapping("/files/sign")
public List<SignedUrl> sign(@RequestBody List<String> fileIds, @RequestParam int expires) {
    return fileService.signBatch(fileIds, expires);  // 复用 wk-module-file-source
}
```

前端调用流程:
1. 前端拿 `fileId`(从上传接口回包)
2. 调 `POST /api/ai/files/sign` 拿签名 URL
3. 拼到 chat-stream 请求的 `messages[i].file_list`

### 2.2 会话历史

新增 2 个端点(代理百炼 session API,**不存自有业务会话**):
- `GET /api/ai/{appKey}/sessions?userId={userId}` → 列表
- `GET /api/ai/{appKey}/sessions/{sessionId}/messages?userId={userId}` → 详情

> **关键决策**:本期**不落库**业务会话,只代理百炼 session。如果主人要自有会话历史,本节改为新增 `ai_session_record` 表,延后到 v1.1。

### 2.3 `bizParams` 入协议

`ChatStreamReq` 加 `bizParams: Map<String, Object>`,后端透传到百炼 `input.biz_params`。
