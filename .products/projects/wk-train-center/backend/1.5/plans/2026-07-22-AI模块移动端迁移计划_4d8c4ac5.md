> 本版基于审核报告反馈 + 二次验证结果 + 二审报告 P0/P1 修正全面完善。

### 1.3 后端 AI 网关（wk-train-center-service）— 不变

**SSE 事件协议**（13 种，已通过代码验证）：

| 事件类型 | 用途 | 前端处理 |
|---------|------|---------|
| `metadata` | 会话元数据（requestId, model） | 存储到会话状态 |
| `content` | AI 正文增量 | 累加到消息 content |
| `thoughts` | 思考/检索阶段节点 | 渲染到 ThoughtsSection |
| `citations` | 参考来源 | 渲染到 CitationList |
| `suggestions` | 建议问题列表 | 渲染到 SuggestionSection（点击即发送） |
| `tool_call` | 工具调用开始 | 渲染到 ToolCallProgress |
| `tool_result` | 工具调用结果 | 更新 ToolCallProgress |
| `usage` | Token 统计 | 可选展示 |
| `file` | AI 生成文件 | 可选展示 |
| `done` | 流结束 | 收尾处理 |
| `error` | 错误（5 类分类） | 友好提示 |
| `progress` | 进度信息（M1.1 预留） | 当前忽略 |
| `interrupt` | 人机交互暂停（M1.1 预留） | 当前忽略 |

**核心接口**（不变）：
- `POST /api/wk/ai/agent/chat-stream` — SSE 流式对话
- `POST /api/wk/ai/agent/dashscope/upload-token` — 文件上传凭证
- `DELETE /api/wk/ai/agent/dashscope/files` — 文件清理
- 答疑 CRUD：`/api/wk/answer/student/*`
- 陪练 CRUD：`/api/wk/training/role/student/*`

## 二、迁移架构决策（修正后）

### 2.1 核心策略：v3 搬运 + v2 补遗 + 移动端改造

```
v3 shared/*.ts ──(复制)──→ mobile/src/shared/ai/
v2 conversationRules ──(TS 重写, 改名 conversationContextRules)──→ mobile/src/shared/ai/
```

## 七、被排除的方案

| 方案 | 排除理由 |
|------|---------|
| **以 v2 为迁移源** | v3 已完成 Vue 3 + TS 现代化重写，用 v2 会重复劳动 |
| **直接 fork v3 代码** | Element Plus 与 Vant 4 不兼容，UI 层需全部重写 |
| **从零搭建移动端 AI** | 移动端已有 11 个 AI 组件 + 766 行 useChatSession，从零搭建是浪费 |
| **使用 iframe 嵌入 v3 页面** | 性能差、交互受限、无法使用原生语音 |
| **迁移 v2 voiceManager.js** | 移动端已有完整语音模块（9 个文件），无需迁移 |
| **共享 monorepo** | v3 用 Element Plus，移动端用 Vant 4，共享 UI 层成本高 |
