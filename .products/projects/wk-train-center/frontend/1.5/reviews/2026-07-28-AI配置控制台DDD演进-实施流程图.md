## 四、配置读取链路(运行时)

```mermaid
flowchart LR
    Req[前端请求<br/>AI 对话] --> Caller[BailianResponsesCaller<br/>useMaasDomain / maasRegion]
    Req --> Executor[AgentReActExecutorImpl<br/>tools / react / apiMode]
    Req --> Service[AgentConfigServiceImpl<br/>getDefaultModel / getSystemPrompt]
    Caller --> Resolver[AgentConfigResolver<br/>合并层]
    Executor --> Resolver
    Service --> Resolver
    Resolver --> DB{ai_agent_config<br/>config_key<br/>enabled=1?}
    DB -->|是 + 有值| UseCfg[用表值]
    DB -->|否/null| UseYml[用 AiAgentProperties<br/>yml 硬编码默认值]
    UseCfg --> Return[返回配置]
    UseYml --> Return

    style Caller fill:#cce5ff
```

**核心**:`Resolver` 是唯一合并入口,所有消费方(3 文件)都委托它。**cfg 表优先,yml 兜底**。

## 六、数据迁移流程(一次性)

```mermaid
flowchart TB
    Start([Migration 执行]) --> Backup[1. 备份<br/>cfg.ai.bailian.data.model<br/>→ _backup_20260728 临时表]
    Backup --> CreateTable[2. 建表<br/>ai_agent_config<br/>DDL 已先执行]
    CreateTable --> Tx[3. START TRANSACTION]
    Tx --> Read1[4. 读 cfg.ai.bailian.data.model]
    Read1 --> Write1[5. 写入 ai_agent_config.models]
    Write1 --> Read2[6. 读 AiAgentProperties 硬编码默认值]
    Read2 --> Filter{白名单过滤<br/>prompts = answer_assistant<br/>+ training_assistant}
    Filter -->|仅白名单 key| Write2[7. 写入其余 config_key 行<br/>REPLACE INTO 幂等]
    Filter -->|含 quiz_generator| Skip[跳过 quiz_generator<br/>留在 AiAgentProperties]
    Skip --> Write2
    Write2 --> Verify{8. 验证<br/>8 行齐全 + 数据非空?}
    Verify -->|否| Rollback[ROLLBACK<br/>报错]
    Verify -->|是| Commit[COMMIT]
    Commit --> Cleanup[9. 清 cfg.ai.bailian.data.model 字段<br/>行保留兼容历史]
    Cleanup --> End([Migration 完成])

    style Backup fill:#cce5ff
    style CreateTable fill:#cce5ff
    style Tx fill:#ffe5cc
    style Filter fill:#ffe5cc
    style Verify fill:#ffe5cc
    style Rollback fill:#ffcccc
    style Commit fill:#ccffcc
    style Cleanup fill:#cce5ff
```

**安全保证**:

- 事务化(START TRANSACTION + COMMIT/ROLLBACK)
- 幂等化(REPLACE INTO 而非 INSERT)
- 白名单过滤(quiz_generator 不写入)
- 验证门(8 行齐全才 COMMIT)
- 执行顺序: 先写新表 → 再清旧字段(中间失败回滚无业务影响)
