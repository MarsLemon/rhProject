## 三、技术栈迁移对照

| V2 模式 | V3 模式 | 适用场景 |
|---------|---------|----------|
| Options API + mixin | `<script setup lang="ts">` + composable | 所有组件 |
| `this.$set(obj, key, val)` | 直接赋值 `obj.key = val` | 动态属性赋值 |
| `this.$forceUpdate()` | `triggerRef(refObj)` | 强制刷新 |
| `this.$message` | `ElMessage` 全量导入 | 消息提示 |
| `this.$confirm` | `ElMessageBox.confirm` | 确认弹窗 |
| `this.$loading` | `ElLoading.service` | Loading 遮罩 |
| `this.$nextTick` | `import { nextTick }` | DOM 更新后回调 |
| `this.$refs.xxx` | `ref<HTMLElement>(null)` 模板绑定 | 组件引用 |
| `Vue.prototype.$xxx` | composable 函数 + 依赖注入 | 全局工具 |
| Vuex modules | Pinia stores | 状态管理 |
| `postData` 函数 | `post<T>()` 类型化 | API 请求 |
| `import echarts/core` | `import * as echarts from 'echarts'` | 图表库 |
| `vue-count-to` 动画 | 静态数字展示 | 数字动画 |
| `mixins/resize.js` | `composables/useChartResize.ts` | 响应式监听 |
