## 💡 拆分经验

1. **Slot 注入是关键**：让父组件向子组件注入复杂子元素（如摄像头组件、计时器），避免子组件过度依赖父级 props。
2. **defineExpose 保留 API**：拆分后外部 API 不变，父组件调用方式无需修改。
3. **类型导出**：子组件的 TypeScript 接口可以导出（如 QuestionNavGroup、QuestionNavItem），方便父组件复用类型。
4. **拆分配套原则**：拆分时同时简化内部结构（如循环+嵌套改为 v-for+template 嵌套），让组件更易读。
5. **拆分模式可稳定复用**：本次拆分与 ThoughtsSection.vue 完全相同的模式（主入口+子组件+slot注入），已验证可适用于考试页面。
