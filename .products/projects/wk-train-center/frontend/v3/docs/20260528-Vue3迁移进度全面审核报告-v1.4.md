## 二、本轮迁移详情

### 2.1 WebExamList/index.vue 考试列表主页

**文件**: `src/views/web/exam/WebExamList/index.vue`

**功能**:
- 检查是否有进行中的考试
- 显示中断考试提示
- 跳转到继续考试

**Vue2 → Vue3 转换要点**:
```typescript
// Vue2
data() { return { breakShow: false, breakId: '' } },
created() {
  checkProcess().then((res) => {
    if (res.data && res.data.id) {
      this.breakShow = true
      this.breakId = res.data.id
    }
  })
}

// Vue3
const breakShow = ref(false)
const breakId = ref('')
onMounted(async () => {
  try {
    const res = await checkProcess()
    if (res.data && res.data.id) {
      breakShow.value = true
      breakId.value = res.data.id
    }
  } catch (error) {
    console.error('检查考试进程失败:', error)
  }
})
```

### 2.2 MyExamPage.vue 我的考试组件

**文件**: `src/views/web/exam/WebExamList/MyExamPage.vue`

- 考试状态筛选
- 日期范围筛选
- 跳转考试记录/错题本

**Vue2 → Vue3 转换要点**:
```typescript
// Vue2
components: {
  ExamStateFlag: () => import('@viewComponents').then((m) => m.ExamStateFlag())
},
methods: {
  reload() { this.$refs.dataGrid.getList() },
  toPaperList(id) { this.$router.push({ name: 'WebPaperList', query: { examId: id } }) }
}

// Vue3
import ExamStateFlag from '@/views/web/exam/components/ExamStateFlag.vue'
const dataGridRef = ref(null)
function reload() { dataGridRef.value?.getList?.() }
function toPaperList(id) { router.push({ name: 'WebPaperList', query: { examId: id } }) }
defineExpose({ reload })
```
