## 文件编码

项目统一使用 **UTF-8**。若 Markdown 或 `index.html` 标题显示乱码：

```bash
npm run fix:encoding
```

然后在编辑器中选择 **UTF-8** →「通过编码重新打开」。

已配置 `.editorconfig`：`charset = utf-8`。
