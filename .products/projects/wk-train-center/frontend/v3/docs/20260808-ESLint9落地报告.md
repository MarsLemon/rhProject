## 3. 规则说明

### 3.1 Vue 2 写法防回流规则（全部 `error`）

| 规则 | 说明 |
|------|------|
| `vue/no-deprecated-v-bind-sync` | 禁止 `.sync` 修饰符（v2 写法，v3 用 `v-model:prop`） |
| `vue/no-deprecated-slot-scope-attribute` | 禁止 `slot-scope`（v2 slot，v3 用 `#default=""`） |
| `vue/no-deprecated-slot-attribute` | 禁止 v2 slot 语法 |
| `vue/no-restricted-syntax`（自定义） | 禁止 `this.$xxx` 全局属性 |
| `no-restricted-syntax`（自定义） | 禁止 `mixins()` 调用（v2 风格，v3 用 composables） |
| `no-restricted-syntax`（自定义） | 禁止 `await validate(async (callback) => {...})` 混用 |

### 3.2 Vue 3 最佳实践（`error`）

| 规则 | 说明 |
|------|------|
| `vue/require-v-for-key` | 强制 `v-for` 有 `:key` |
| `vue/require-explicit-emits` | 强制 emit 显式声明（defineEmits 泛型） |

### 3.3 Vue 3 建议（`warn`）

| 规则 | 说明 |
|------|------|
| `vue/require-default-prop` | 建议 props 提供默认值 |
| `vue/require-prop-types` | 建议 props 标注类型 |
| `vue/no-v-html` | 警告 v-html（XSS 风险） |

### 3.4 TypeScript 规则

| 规则 | 级别 | 说明 |
|------|------|------|
| `@typescript-eslint/no-explicit-any` | warn | 禁止 `any`，允许 `as unknown as` 类型擦除 |
| `@typescript-eslint/no-unused-vars` | error | 禁止未使用变量（`_` 前缀忽略） |

## 6. 遗留 Warnings 分析

| 规则 | 数量 | 说明 | 建议处理方式 |
|------|------|------|-------------|
| `@typescript-eslint/no-explicit-any` | 1164 | 合法类型擦除（`as unknown as T`） | 逐步添加类型 |
| `vue/no-v-html` | 36 | 富文本渲染（题目/课程内容） | 有风险场景加 suppression |
| `vue/require-default-prop` | 13 | props 未设默认值 | 逐步补全 |

**说明**：`no-explicit-any` 的 1164 个 warning 主要是以下合法场景：
- API 响应类型未知时：`res as unknown as ApiResponse`
- 第三方库类型缺失：`window.xxx as any`
- 动态数据处理中的类型宽泛

## 8. 下一步建议

### 短期（1-2 周）
1. **降低 `no-explicit-any` 数量**：重点模块（`api/`、`stores/`）逐步添加精确类型
2. **处理 `no-v-html`**：对富文本渲染场景使用 `// eslint-disable-next-line` suppression
3. **补充 `require-default-prop`**：必填 props 添加默认值

### 中期（持续）
1. **CI/CD 集成**：`npm run lint` 写入 GitHub Actions / CI 流水线
2. **pre-commit hook**：使用 `husky` + `lint-staged`，每次提交自动检查
3. **规则收紧**：待 warning 数量降至 500 以下后，可将 `--max-warnings` 降至 500

### ESLint 配置调优
- 当前 `--max-warnings 2000` 较为宽松，团队稳定后可降至 `1000`
- 考虑添加 `import/no-unresolved`、`vue/multi-word-component-names` 等规则
