### 2.1 WebCourseList/index.vue 课程列表主页

**文件**: `src/views/web/course/WebCourseList/index.vue`

**功能**:
- 5个 Tab：公共课程、教师中心、指派课、自学课、学习记录
- Tab 状态缓存到 sessionStorage
- 子组件刷新联动

**Vue2 → Vue3 转换要点**:
```typescript
// Vue2
data() { return { activeTab: 'open' } },
methods: {
  handleTabClick() { ... },
  reloadMy() { this.$refs.selfStudy.reload() }
}

// Vue3
const activeTab = ref('open')
const assignedRef = ref<any>(null)
const selfStudyRef = ref<any>(null)
function handleTabClick() {
  ;(selfStudyRef.value as any)?.reload?.()
}
```

### 2.2 OpenCoursePage.vue 公共课程

**文件**: `src/views/web/course/WebCourseList/OpenCoursePage.vue`

**功能**:
- DataGrid 卡片列表展示
- AI 智能搜索对话框
- 课程收藏/加入功能
- 字典树形分类

**Vue2 → Vue3 转换要点**:
```typescript
// Vue2
methods: {
  handleJoin(data) {
    joinCourse(data.id).then(() => {
      this.$emit('join')
      data.hasJoin = !data.hasJoin
    })
  }
}

// Vue3
async function handleJoin(data: any) {
  try {
    await courseJoin(data.id)
    emit('join')
    data.hasJoin = !data.hasJoin
  } catch (error) {
    console.error('加入课程失败:', error)
  }
}
```
