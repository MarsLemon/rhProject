**共同特征**:
- API 路径从 `/course/file` → `/admin/course/file` (命名空间重构)
- 所有 axios 调用都在 mixin/API 模块中，不在当前 `.vue` 文件
- AST 提取器无法识别外部引用的 axios 调用

---

### **关键发现**

1. **"dynamic"URL 全是误报**
   - AST 看到 `axios.get('/api/xxx' + someVar)` → 标记为 dynamic
   - 但实际代码是 `import { getApi } from '@/api/module'` → 静态路径

2. **mixins 中的 axios 未被识别**
   - v2: `mixins: [useFileUploadState]` ← axios 在这里面
   - v3: inline ref/reactive 管理
   - 提取器看不到 mixin 内部实现

3. **API 模块抽象层设计良好**
   - v2: `import { batchSaveData } from '@/api/course/file'`
   - v3: `import { batchSaveData } from '@/api/admin/course/file'`
   - 只是命名空间调整，功能完全一致
