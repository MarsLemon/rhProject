## 三、修正后的具体步骤

### ✅ Step 1: Grep 验证 (优先级 P0)

**目的**: 先确认 Vuex→Pinia 的实际映射关系，再做分类

**命令**:
```bash
# 1. 提取所有 vuex_not_migrated entries
jq '.severity_breakdown.p1_logic_deviation[] | select(.issues[].type=="vuex_not_migrated")' vue2-v3-migration-audit.json

# 2. 列出所有 affected files
grep -E "vuex_not_migrated.*description" audit-reports/p1-logic-deviation.md | cut -d'|' -f2 | sort -u

# 3. 提取 Vuex action 列表
grep -oP '"vuexActions":\s*\[[^\]]+\]' vue2-v3-migration-audit.json | grep -oP '"[^"]+(?=")' | sort -u
```

**预期产出**:
- 完整文件清单 (预计 27 个)
- 完整 action 清单 (预计 44 个)

**时间**: ~5 分钟

### ✅ Step 2: Pinia Store 架构检查 (P0)

**检查每个 Pinia store**:
```bash
cd wk-train-center-ui-v3/src/stores/modules/
ls *.ts  # 应该有 7 个文件
```

**逐 store 验证**:
```typescript
// stores/modules/user.ts
export const useUserStore = defineStore('user', {
  state: () => ({ token: '', hasToken: false }),
  actions: {
    async fetchMsg() { /* ... */ },  // ← 检查是否有对应的 Vuex action
    async login({ commit }, payload) {/* ... */}
  }
})
```

**分类标准**:
| 情况 | 判定 | 说明 |
|------|------|------|
| v3 store 有同名 action | ✅ 已迁移 | action 存在且等价 |
| v3 store 有改名 action | 🟡 重构 | action 改名/合并 |
| v3 store 无此 action | ❌ 未迁移 | 需要补全 |

**时间**: ~15 分钟

---

### ✅ Step 3: 逐文件对比 (P1)

对 27 个文件的每一个:

**v2 code**:
```javascript
// App.vue created hook
created() {
  this.$store.dispatch('user/fetchMsg')
  this.fetchMsgOnce()
}
```

**v3 code**:
```typescript
// App.vue onMounted
onMounted(() => {
  userStore.fetchMsg()  // ← 检查是否调用正确
})
```

**判定**:
- ✅ 等价迁移：功能一致，只是调用方式变了
- ⚠️ 需人工：可能需要调整参数或返回值
- ❌ 缺失：v3 完全没有对应逻辑

**时间**: ~45 分钟 (27 个文件 × ~1.5 分钟/文件)
