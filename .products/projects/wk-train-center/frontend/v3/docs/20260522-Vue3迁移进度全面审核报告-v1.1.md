## 二、本轮修复详情

### 2.1 iframe 错误通知

**文件**: `src/router/guards/index.ts`

**问题**: 在 iframe 模式下检测到未登录时，只有 console.error，没有通知父窗口

**修复**:

```typescript
if (isInIframe) {
  console.error('[培训] iframe 模式未检测到登录凭证')
  // 向父窗口发送 Token 错误通知
  window.parent.postMessage(
    { type: 'CHILD_TOKEN_ERROR', message: '未检测到登录凭证，请重新登录' },
    '*'
  )
  NProgress.done()
  return { path: '/pages/login/login', query: { redirect: to.fullPath } }
}
```
