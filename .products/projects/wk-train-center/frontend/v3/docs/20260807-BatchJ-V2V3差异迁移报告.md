- 脚本缺少 `defaultParams` 数据

**已增量迁移**：
```typescript

:default-params="defaultParams"

// 脚本添加
// 重置按钮默认值：保留 courseId，清空用户输入的 fileType / title
const defaultParams = { courseId: '' }

// options 添加
aiPpt: { enable: true },
```

**验证**：`npm run typecheck` ✅ 通过。
