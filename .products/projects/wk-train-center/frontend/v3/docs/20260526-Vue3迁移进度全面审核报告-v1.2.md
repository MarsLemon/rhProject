## 二、本轮迁移详情

### 2.1 WebStatNums 统计数字组件

**文件**: `src/views/web/dashboard/components/WebStatNums.vue`

**功能**:
- 显示待参加考试、待学习课程、今日学习时长、累计学习时长
- 数字滚动动画效果（使用 vue-count-to）
- 通过 `update` 事件向上传递完整数据

**Vue2 → Vue3 转换要点**:
```typescript
// Vue2 Options API
export default {
  data() {
    return { stat: { examCount: 0, ... } }
  },
  created() { this.fetchData() },
  methods: { fetchData() { ... } }
}

// Vue3 Composition API
const stat = ref<DashboardStatData>({ ... })
const siteData = settingsStore.siteData
onMounted(() => { fetchData() })
```

### 2.2 WebNoticeList 滚动公告组件

**文件**: `src/views/web/dashboard/components/WebNoticeList.vue`

**功能**:
- 自动轮播公告（3秒切换）
- 新公告标识（7天内）
- 点击跳转详情

**Vue2 → Vue3 转换要点**:
```typescript
// Vue2
methods: {
  startAutoPlay() { this.timer = setInterval(...) },
  stopAutoPlay() { clearInterval(this.timer) }
}

// Vue3
let timer: ReturnType<typeof setInterval> | null = null
function startAutoPlay() {
  stopAutoPlay()
  timer = setInterval(...)
}
function stopAutoPlay() { ... }
```

### 2.3 WebTaskCenter 任务中心组件

**文件**: `src/views/web/dashboard/components/WebTaskCenter.vue`

**功能**:
- 课程/考试 Tab 切换
- 课程封面图、进度展示
- 考试截止时间、次数限制

**Vue2 → Vue3 转换要点**:
```typescript
// Vue2
props: { courses: Array, exams: Array },
methods: { toCourse(id) { this.$router.push(...) } }

// Vue3
withDefaults(defineProps<{ courses?: TaskItem[], exams?: TaskItem[] }>(), { ... })
const router = useRouter()
function toCourse(id: string | number) { router.push(...) }
```
