关键迁移要点：
- 标记 + 取消：v2 this.$confirm → v3 ElMessageBox.confirm（type: 'warning'）
- 实时预览：v2 marked.parse 默认异步 → v3 marked.parse(text, { async: false })
- XSS 防护：v-html 渲染前调用 `@/utils/sanitize`
- API base：v2 process.env.VUE_APP_BASE_API → v3 import.meta.env.VITE_APP_BASE_API
- 响应式 props：`computed({ get, set })` 桥接 v-model，避免 `vue/no-mutating-props`
- 表单双向：`@change="syncWebExtractor"` 同步联网/网页提取开关

### 5. Utils next-step 补全（P2 · 已完成）

| 文件 | 行数 | 说明 |
|------|------|------|
| `utils/next-step.ts` | 165 | v2 next-step.js 的 Vue3 移植 |

迁移要点：
- v2 `ctx.$createElement` + `Vue.observable` → v3 直接返回 HTML 字符串 + `dangerouslyUseHTMLString: true`
- v2 `MessageBox.confirm`（element-ui）→ v3 `ElMessageBox.confirm`（element-plus）
- v2 `ctx.$confirm` 实例方法 → 直接调用全局 ElMessageBox（无需 ctx）
- v2 三合一确认框（checkbox + input 嵌入）→ 拆为"先 confirm、再 prompt"两步，调用方 `.then(({ action, customName }))` 形态保持不变
- 文本安全：新增 `escapeHtml()` 防止提示文案注入

## 关键 v2 → v3 模式对照

| Vue2 模式 | Vue3 等价模式 |
|-----------|---------------|
| `this.$confirm(content, ...)` | `ElMessageBox.confirm(content, ...)` |
| `this.$message.success/error` | `ElMessage.success/error` |
| `ctx.$createElement(...)` (JSX) | `h(...)` 或 `dangerouslyUseHTMLString: true` |
| `Vue.observable({ ... })` | `reactive({ ... })` |
| `process.env.VUE_APP_BASE_API` | `import.meta.env.VITE_APP_BASE_API` |
| `::v-deep` / `>>>` | `:deep(...)` |
| `slot="reference"` / `slot="footer"` | `<template #reference>` / `<template #footer>` |
| `marked.parse(text)` | `marked.parse(text, { async: false })` |
| `import ElementUI from 'element-ui'` | `import { ElMessage, ElMessageBox } from 'element-plus'` |
